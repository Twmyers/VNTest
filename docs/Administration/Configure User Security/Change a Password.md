



# Change a Password

Passwords must contain ASCII characters only to work in
Value
Navigator 2019 or higher. Passwords with non-ASCII characters
will work in versions prior to 2019 unless those projects are upgraded
to 2019. See

To reset passwords you must have permission to modify security.

To reset a user’s password

1.  From the **Administration** menu, select **Security Settings.**
2.  In the **Security Settings** dialog box, select the **Users** tab.
3.  Right-click the user’s name and click **Reset User Password**.
4.  Enter a new password and click **OK**.
