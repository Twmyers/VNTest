



# Create Users

Use this procedure to create a single user and assign that user a
password.

To assign the user a role or policies, see
[Assign Policies to Users](Assign%20Policies%20to%20Users.md) or
[Assign Roles to Users](Assign%20Roles%20to%20Users.md).

To import users from an active directory, see
[Import Users from an Active Directory](Import%20Users%20from%20an%20Active%20Directory.md).

To create a user

1.  From the **Administration** menu, select **Security Settings**.
2.  On the **Users** tab, click **Create User**.
3.  Enter a **User Name** and **Password** and click **OK**.
