

# User Security Overview

Configuring user security consists of these basic steps:

1.  [Create Users](Create%20Users.md) or
    [Import Users from an Active Directory](Import%20Users%20from%20an%20Active%20Directory.md)
2.  [Create Roles](Create%20Roles.md),
    which are groups of policies (permissions)
3.  [Edit Policies](Edit%20Policies.md)
4.  [Assign Roles to Users](Assign%20Roles%20to%20Users.md)and/or
    [Assign Policies to Users](Assign%20Policies%20to%20Users.md)to users

For an overview of security policies see
[Security Policies](Security%20Policies.md).
