



# Delete Capital Actuals

Delete Capital Actuals removes actual capital cost values imported from
Execute.

To delete capital actuals

1.  Select the entities with capital actuals you want to delete.
2.  In the **Administration** menu, select **Data Cleanup** \&gt; **Delete
    Capital Actuals**.
3.  If required, in the Delete Capital Actuals dialog box, select
    **Apply to child entities**.
4.  Click **OK**.
