



# Lock or Unlock a Project

To lock a project

1.  In the **Administration** menu, select **Lock Project**.
2.  In the Lock Project dialog box, enter a comment explaining why the
    project is locked (optional) and click **OK**.

When a project is locked, a checkmark appears next to **Lock Project**
in the **Administration** menu.

To unlock a project, from the **Administration** menu, select **Lock
Project**.
