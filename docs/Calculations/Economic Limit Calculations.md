

# Economic Limit Calculations

For a particular one-month period the Net Operating Income is negative,
but for a series of subsequent months the Net Operating Income is
positive and much more positive than the single negative month. Using
the following series of Net Operating Income monthly values…

+50, +40, +30, +20, +10, -1, +2, +3, +2, +1, -2, -3, -3, -3

When a simple economic limit test is to find when the Net Operating
Income goes negative for the first time, the result for the above series
would be in the sixth period, meaning only the first five periods would
be considered for the total project economics.

But if the economic limit test was done to find the point at which the
cumulative Net Operating Income was at its peak (highest cumulative Net
Operating Income), the result for the above series would be the tenth
period, and the first ten periods would form the total project
economics. This has implications not only for the value of the project,
but also for the volumes which could potentially be claimed as reserves.

In the situation that is described above, +50, +40, +30, +20, +10, -1,
+2, +3, +2, +1, -2, -3, -3, -3
Value
Navigator will not put the economic limit at the month with -1
values, but rather at the month with -2 so it does ‘call the economic
limit the point in time when the cumulative Net Operating Income is at
its peak’.
