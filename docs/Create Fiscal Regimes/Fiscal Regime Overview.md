

# Fiscal Regime Overview

Value
Navigator includes fiscal regime data for Canada and the United
States. This regime data is used when you set up interests for a
Canadian or American entity in **Economics \| Interest & Royalties**.
However, if you are drilling outside of Canada or the United States or
you want to customize the existing regimes, you can set up or edit
custom regimes for any country, province, or state.

Creating a regime involves these basic steps:

1.  [Create a Fiscal Regime](Create%20a%20Fiscal%20Regime.md) (or copy an existing regime). Add regime
    information such as the type (concession or contract, before tax or
    tax) county, currency, etc.
2.  Add [Add Entity-level Regime Inputs](Add%20Entity%20Level%20Regime%20Inputs.md) or
    [Add Regime-level Inputs](Add%20Regime%20Level%20Inputs.md).
3.  [Create Formulas for Regime Variables](Create%20Formulas%20for%20Regime%20Variables.md)
4.  [Preview Regime Output](Preview%20Regime%20Output.md).
