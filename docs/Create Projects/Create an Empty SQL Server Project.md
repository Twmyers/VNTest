



# Create an Empty SQL Server Project

To create a
[SQL Server or SQL Server - Windows Authentication SQL Server: When accessing the database from outside Value Navigator, you will need a password. SQL Server - Windows Authentication: When accessing the database from outside Value Navigator, Windows Authentication is used.](#) project,
you must have SQL Server administrator rights.

Before creating an Oracle or SQL Server project, you need to configure
the connection settings in [User Options: Connection Settings](../Options/User%20Options/User%20Options%20Connection%20Settings.md).



You must use at least SQL Server 2008 for
Value
Navigator 6 or higher databases.



To create an empty SQL Server (or SQL Server - Windows Authentication)
project

1.  On the **File** menu, click **Open**.
2.  In the Project Launcher, click **Create New Project**.
3.  In the Project Name field, type a name.
4.  In File, browse to a location to save the new .vndl file (a
    Value
    Navigator-specific connection link for server-based project
    files).
5.  From the Type list, select **SQL Server** or **SQL Server - Windows
    Authentication**.
6.  In Server, type the name of the server or click to select it from
    the list.
7.  From the Res. Cat. Template list,
    select the
    [template](../Reserves%20Management/Configure%20Reserves%20Categories.md#Reserves)
    you want to use.
8.  Click **OK**.

A new project is created in the location you specified and
Value
Navigator opens. The new project appears in the Project Launcher
the next time you open it.
