



# Create an Oracle Project from a Production Data File

To create an Oracle project, you must have Oracle server administrator
rights or you must ask a DBA to create an Oracle user for you. Once the
user is created, you can use it to create a new project. You will also
require the Oracle password.

To create an Oracle project you need to configure the connection
settings in User Options. See [User Options: Connection Settings](../Options/User%20Options/User%20Options%20Connection%20Settings.md).

It is highly recommended that you review and understand the [Fit
Settings](../Options/User%20Options/User%20Options%20Forecast%20Settings.md)
and [Import
Parameters](../Options/User%20Options/User%20Options%20Import%20Parameters.md)
in the User Options before importing production data. These settings
affect how data is imported and how forecasts are created in
Value
Navigator.

To create an Oracle project from a production data file

1.  On the **File** menu, click **Open**.
2.  In the Project Launcher, click **Create From Import**.
3.  Browse to the production data file and click **Open**.
4.  In Project Name, type a name.
5.  In File, browse to a location to save the .vndl file (a
    Value
    Navigator-specific connection link for server-based project
    files).
6.  From the Type list, select **Oracle**.
7.  In Server, type the server name or select it from the list.
8.  If you do not want to use the default Oracle User name, type a new
    name.
9.  In Password, type the Oracle server password.
10. Enter your User Name and Password.
11. From the Res. Cat. Template list,
    select the
    [template](../Reserves%20Management/Configure%20Reserves%20Categories.md#Reserves)
    you want to use.
12. Click **OK**.
13. In the Import Options dialog box, click **Edit** to change the
    options or click **Next** to continue.
    

    Depending on the last production dates in your data file, you might
    be asked to
    [Set the Current Month](Set%20the%20Current%20Month.md).

    
14. Click **Finish**.
