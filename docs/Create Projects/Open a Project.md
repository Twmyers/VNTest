



# Open a Project

To open a project

1.  On the **File** menu, click **Open**.
2.  Do one of the following:
    | In the project you want to open | Do this                                |
    |---------------------------------|----------------------------------------|
    | Is in the recent list,          | Double-click the project.              |
    | Is not in the recent list,      | Click **Browse** and open the project. |
