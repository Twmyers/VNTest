



# Remove the Password from a Project Connection File

By default, project connection files (.vndl) for Oracle and SQL Server
projects contain the password (encrypted). This means that any user who
opens the file can access the project without entering a password. If
you want to make the file accessible to other users, but require them to
enter the password you give them, you can remove the password from the
connection file.

To remove the password from a connection file

1.  Launch
    Value
    Navigator and close the Project Launcher. If you have a
    project open, click ![](../Images/Remove-the-Password-from-a-Project-Connection-File-1.png) to close the project
    (Value
    Navigator remains open).
2.  From the **File** menu, select **Edit** or **Create a Project
    Connection File**.
3.  In the **File Path**, click**![](../Images/Remove-the-Password-from-a-Project-Connection-File-2.png).**
4.  Browse to the .vndl file you want to edit and click **Open**.
5.  Select **Exclude password from file.**
6.  Click **Save** and **Close**.
