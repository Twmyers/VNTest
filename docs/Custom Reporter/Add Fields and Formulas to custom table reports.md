

# Add Fields and Formulas to Custom Table Report Objects

To add fields and formulas to an object

1.  Open the Report Editor
2.  Drag the field/formula from the Fields and Formulas window into the
    top row of the report outline. The field/formula creates a new
    column in the report outline.
3.  Double-click the field/formula. A new column is inserted into the
    report.
