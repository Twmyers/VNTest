

# Create a Custom Graph Report: Overview

To create a new graph report

1.  From the **Tools** menu, select **Custom Reports** or click
![](../Images/Create-a-Custom-Graph-Report-1.png).
2.  Click **Add** to open the New Report Object dialog box.
3.  Select **Graph**.
4.  Select the Type of information to report and click **OK**.
5.  In the Report Editor, [add
    fields](Add%20Fields%20and%20Formulas%20to%20custom%20graph%20reports.md)
    (columns) to the report.
6.  [Group the fields](Group%20Fields%20in%20Custom%20Graph.md).
7.  [Format the report](Format%20Custom%20Graph%20Reports.md).
8.  [Add filters to the
    report](Add%20Filters%20to%20Custom%20Graph.md).
