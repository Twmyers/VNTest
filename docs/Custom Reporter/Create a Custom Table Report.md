

# Create a Custom Table Report: Overview

To create a new table report

1.  From the **Tools** menu, select Custom Reports or click
![](../Images/Create-a-Custom-Table-Report-1.png) on the Standard toolbar.
2.  Click **Add** to open the New Report Object dialog box.
3.  Select **Table**.
4.  Select the **Type** of information to report and click **OK**.
5.  In the Report Editor, [Add Fields and Formulas to Custom Table Report Objects](Add%20Fields%20and%20Formulas%20to%20custom%20table%20reports.md)to the report.
6.  [Group Fields in Custom Table Reports](Group%20Fields%20in%20Custom%20Table.md).
7.  [Format Custom Table Report Properties](Format%20Custom%20Table%20Report.md).
8.  [Add Filters to Custom Table Reports](Add%20Filters%20to%20Custom%20Table.md).
