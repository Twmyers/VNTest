

# Nest Group Fields in Custom Table Reports

Group Fields can be nested within each other. This allows you to group
your results by two or more fields.

To nest group fields

1.  Drag fields from the Fields and Formulas window and drop them into
    the **Group** window. The field on the top is the highest level of
    the grouping and fields below are lower levels of grouping.
2.  In the Group Fields window, right-click a group field, point to
    **Expand Group** and select **Summarized** or **Expanded**.

See [Summarize Grouped Fields in Custom Table Reports](Summarize%20Grouped%20Fields%20in.md).
