



# Apply an Economic Limit

Value
Navigator allows the user to use either Net Operating income or
Before Tax Cash Flow to determine if entities in a project have reached
an economic limit.

Also see [Project Options: Economics](../../Options/Project%20Options/Project%20Options%20Economics.md).

To apply an economic limit to an entity

1.  Go to **Economics \| General**.
2.  Under **Economic Data**, select **Apply Economic Limit**.
