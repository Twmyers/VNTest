



# Enter Incremental Costs

When you use the incremental forecasting mode (see [Create an Incremental Forecast](../../Forecasting/Create%20and%20Edit%20Declines/Create%20an%20Incremental%20Forecast.md)), you only need
to add the incremental portion of your operating or capital costs.
However, you must create the incremental cost by overriding the capital
or operating costs tab, creating a new cost, and entering the
incremental amount.



The Project Start date is not used in the PDP reserves category and only
affects costs entered as overrides.



To enter an incremental operating or capital cost

1.  Go to the **Operating** or **Capital Costs** tab and click
    **Override**.
2.  Add a new cost.\
    The Base operating or capital cost (from PDP) is displayed with a
    light blue bar below the cost name (if Show
    base costs is enabled at the top of the costs screen). The
    new incremental cost is displayed with a dark blue bar.
3.  Enter the incremental portion of the cost in the date it is to be
    incurred.

You can now create a Project Start Date for the incremental forecast and
costs. Moving the Project Start Date moves the start of the incremental
forecast and incremental costs together. See [Add or Adjust the Project Start Date](../../Entity%20Management/Schedules/Add%20or%20Adjust%20the%20Project%20Start%20Date.md).
