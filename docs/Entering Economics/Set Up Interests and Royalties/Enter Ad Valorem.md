



# Enter Ad Valorem

If Ad Valorem has been set up in a fiscal regime as an entity-level
input, it is displayed on **Economics \| Interest & Royalties** if the
Before Tax Calculation is selected for that regime. Ad Valorem can only
be added to entities designated as US or International.

To enter an Ad Valorem percentage

1.  Go to **Economics \| Interest & Royalties**. The Ad Valorem table is
    displayed beneath the Interest Properties.
2.  Enter the Ad Valorem percentages in the applicable dates.



You can copy Ad Valorem from one entity to others using the Input
Copier.
