



# Enter Alberta Capital Cost Index (ACCI)

Wells in Alberta that operate under the Modernized Royalty Framework
will have the ACCI applied when royalties are calculated.



The C\* value calculated on the **Interests and Royalties** tab is not
factored by ACCI. The ACCCI is applied when economics are run.



To enter the ACCI

1.  On the **Tools** menu, point to **Global Project Data** and select
    **Price Decks**.
2.  In the active price deck (and any scenario price decks), select
    **Tax Rates** and browse to **Alberta Capital Cost Index**.
3.  Enter the index value (%) on the required year.

The ACCI tracks year-over-year inflationary or deflationary changes in
the industry. The ACCI will initially be set to 100% in 2017, and
allowed to “float” on an annual basis as a function of changes in
industry costs. The value will be periodically modified by the Alberta
government.
