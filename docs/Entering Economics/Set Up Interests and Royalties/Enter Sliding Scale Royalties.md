



# Enter Sliding Scale Royalties

All sliding scale overrides are entered on **Economics \| Interest &
Royalties. T**here are three different places to enter sliding scale
overrides on this tab, depending on who is receiving the overrides.

- Royalties received
- Royalties paid to partners
- Royalties paid to mineral owners (appears only when **Freehold** is
  selected for Mineral Owner)

To enter a sliding scale override (payable or receivable)

1.  Select **Economics \| Interest & Royalties**.
2.  In the window on the left, select the interest to which you want to
    add the sliding scale royalties.
3.  Beside the interests window, click the empty cell next to **Sliding
    Scale Override** and then click the ellipsis to open the **Sliding
    Scale** dialog box.\*
4.  Edit the values and click **OK**.



If the Sliding Scale Override is not displayed in the list next to the
interests window, click empty list at the top of the screen and select
it.



To enter a Freehold Mineral Owner sliding scale override

1.  On **Economics \| Interest & Royalties**, select **Freehold** as the
    Mineral Owner Type.
2.  Do one of the following:
    | To | Select | And |
    |----|----|----|
    | Use the crown calculations for the province based on the production category selected for the interest, | **Crown Equiv.** for the Calculation Type | Finish. |
    | Enter a percentage, | **Royalty %** for the Calculation Type | Enter a percentage in the **Royalty** field. |
    | Enter sliding scale royalty parameters, | **Royalty %** for the Calculation Type | Click the ellipse in the **Royalty** field and enter the sliding scale parameters. |
