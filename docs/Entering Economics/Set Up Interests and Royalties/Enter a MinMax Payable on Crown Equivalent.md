



# Enter a Min/Max Payable on Crown Equivalent

You can enter a minimum and maximum Crown Equivalent percentage for oil
or gas leases on Freehold or Indian Lands.

To enter a minimum and maximum

1.  On **Economics \| Interests & Royalties**, select the interest to
    which you want to apply the minimum and maximum.
2.  Under Entity Properties, select a **Royalty Calculation**.\
    Royalty parameters are displayed on the right.
3.  For **Owner Type**, select **Indian Lands** or any **Freehold**
    type.
4.  For **Calculation Type**, select **Crown Equivalent**.
5.  Select the **Production Category** and **Incentive Type**, if
    applicable.\&gt;
6.  Click ![](../../Images/Enter-a-MinMax-Payable-on-Crown-Equivalent-1.jpg) next to Royalty (%).
7.  For **Oil and/or Gas**, enter a minimum and maximum value and click
    **OK**.
