



# Select Incentives

The incentives available for selection depend on the jurisdiction and
phase of the entity. Once you select an incentive, additional parameters
required for that incentive are displayed.

For dollar-based incentives, you can enter a Balance Effective Date,
which enables you to specify when the Gross Balance Remaining should be
decremented. If you do not enter a Balance Effective Date, the balance
is decremented from the production start date.

See [Enter a Payout Reversion or Incentive Balance and Effective Date](Enter%20a%20Payout%20Reversion%20or%20Incentive%20Balance%20and%20Effective%20Date.md).

To select incentives

1.  Go to **Economics \| Interests & Royalties**.
2.  Under **Incentives**, select an **Incentive Type**.
3.  Enter the required incentive calculation parameters.
