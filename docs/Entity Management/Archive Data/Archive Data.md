



# Archive Data

Archiving enables you to save data that does not change over time as
program versions and calculations change. By archiving your project you
can save economic, technical, entity, and project data. See
[Create an Archive](Create%20an%20Archive.md) for more details.

You can also report on archive data in archive reports and compare
archives to your current project or to other archives. See
[Compare Archives](Compare%20Archives.md).
