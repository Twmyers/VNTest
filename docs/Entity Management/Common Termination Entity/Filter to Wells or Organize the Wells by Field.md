



# Filter to Wells or Organize the Wells by Field

Before creating a Common Termination Entity (CTE), you can do one of the
following:

- Organize your wells by Field (see [Create or Edit an Entity Hierarchy](../View%20and%20Organize%20Entities/Create%20or%20Edit%20an%20Entity%20Hierarchy.md) ) and then
  create a cost entity based on the wells in the Field folder.
- Create a cost entity and then filter to the cost entity and the wells
  you want to include in the CTE (and then create the CTE from those
  entities).
