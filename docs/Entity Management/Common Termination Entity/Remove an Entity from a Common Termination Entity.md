



# Remove an Entity from a Common Termination Entity

To remove a well from a common termination entity (CTE)

1.  In the Entity Explorer, expand the CTE you want to remove an entity
    from.
2.  Right-click the entity (or entities) you want to remove and click
    **Remove from Common Termination Entity**.
3.  Click **Yes**.

The entity is removed from the group and returned to the well list.
