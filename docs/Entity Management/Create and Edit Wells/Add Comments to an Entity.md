



# Add Comments to an Entity

You can add comments on Info \| Comment
(described below) or [directly to a
graph](../../Graphing/Annotate%20Graphs/Add%20Graph%20Comments.md) on
Predictions \| Declines.

To add comments and/or link documents to an entity

1.  In the Entity Explorer, select the entity to which you want to add a
    comment.
2.  Go to **Info \| Comments** and click **Add**.
3.  Select a **Comment Type** and **Reserves Category**.
4.  Type a comment.
5.  To link a document to the entity, click ![](../../Images/Add-Comments-to-an-Entity-1.png) next to
    Link.
    

    Linking a document creates a hyperlink to the document’s location.
    It does not attach the document.

    
6.  Browse to the file and click **Open**.
7.  Click **OK**.
