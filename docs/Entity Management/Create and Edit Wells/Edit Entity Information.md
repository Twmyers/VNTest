



# Edit Entity Information

To edit entity information, do one of the following

1.  In the Entity Explorer, right-click the entity you want to edit and
    click **Edit Entity**.
2.  Edit the information and click **OK**.

OR

- Edit the information displayed in the Data View and click **Save**
![](../../Images/Edit-Entity-Information-1.jpg).

OR

- Edit the information displayed on the **Properties** tab in the bottom
  left of the screen. Only bold fields are editable.



Changing the phase causes the forecast and volumetrics of the old phase
to be overwritten with a new forecast.
