



# Manage Entity Data

You can use the Data Manager to copy reserves category data to other
reserves categories, merge plans, or remove inputs.

To access the Data Manager, do one of the following:

- Right-click in the **Summary** window and select **Copy Reserves
  Category Data**, **Advanced Copy**, **Merge Plans**, or **Remove
  Inputs**.
- Select **Data Manager** from the **Entity** menu.

See the topics below for more information on each tab in the Data
Manager.
