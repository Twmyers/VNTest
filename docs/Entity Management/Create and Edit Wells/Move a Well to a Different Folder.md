

# Move a Well to a Different Folder

Because the hierarchy is based on values stored in fields on
Wells and General Economics \| Wells Info and
Custom Fields (in Data View), there is no drag and drop method of
moving entities to different folders. To move an entity to a different
folder, you need to edit the values stored in the fields used to
organize the Entity Hierarchy.

In the example below, the hierarchy is based on the Profile field on
Wells and General Economics \| Wells Info and
Custom Fields. The *Horizontal* and *Vertical* values determine
the name of the folder the wells belongs to. Editing those values moves
the wells to a different folder.

To move wells to a different folder

1.  On Wells and General Economics \| Wells Info
    and Custom Fields (in Data View), determine which wells to
    move and which fields need to be modified.

    

     

2.  Edit the value(s) in the required fields (type over or copy and
    paste) and click Save.

    

     

The wells have been moved to the new folder location.
