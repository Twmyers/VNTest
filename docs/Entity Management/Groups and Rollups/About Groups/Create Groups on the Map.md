



# Create Groups on the Map

You can also point to a location on the Map tab and create a group. The
Latitude and Longitude of your mouse pointer position are displayed at
the bottom left of the map.

To create a group on the map

1.  Click the **Map** tab.
2.  Hold the **Ctrl** button and click the wells you want to use in the
    group to select them.
3.  In the entity Explorer, right-click and click Create as Group.
4.  Type a name for the group
5.  Under **Phase**, select **Oil** or **Gas**.
6.  Under **Calculate Reserves Categories**, select the reserves
    categories you want to calculate.
7.  Edit other group information, as required, and click **OK**.



You must select **Wells and Groups** or **Groups** from the **Entity
Type** list in the Standard toolbar in order to see your group once you
have created it.
