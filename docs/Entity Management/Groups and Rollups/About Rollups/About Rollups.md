



# About Rollups

Rollups are created to represent total production and forecasts for a
set of wells as the aggregate of the technical data for individual wells
included in the set. Rollups apply only to technical data - they do not
sum the economic data. Economics cannot be run on a rollup, but
economics can still be run on individual wells within a rollup.

When a rollup is created, the production history and forecast data for
each well is summed, as seen on Predictions \|
Declines in Entity View. The summed forecast cannot be edited
directly; it can only be edited by editing the forecasts of its child
wells. Click the rollup to recalculate after adding/removing wells or
modifying a child well forecast.

When wells are added to rollups, the wells are not moved from the
general well list, so wells can appear in more than one rollup at a
time, and in a rollup and a group at the same time.

To see rollups in
Value
Navigator, select the Rollups view with the selector on the Main
toolbar.
