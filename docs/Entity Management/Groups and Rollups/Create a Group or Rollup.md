



# Create a Group or Rollup

Also see
[About Groups](About%20Groups/About%20Groups.md) and
[About Rollups](About%20Rollups/About%20Rollups.md).

To create a group or rollup

1.  In the Explorer, select the wells you want to create as a group or
    rollup.
2.  Right click the selected wells, point to **Create as**, and click
    Group or **Rollup**.
3.  Enter a name and edit the properties, if required.
4.  Click **OK**.

To create a working interest rollup, see
[Create a Working Interest Rollup](About%20Rollups/Create%20a%20Working%20Interest%20Rollup.md).
