



# Create a Calculated Plan

Calculated plans enable you to define calculations between plans and
view the incremental results in each reserves category.

To create a calculated plan

1.  On the **Tools** menu, point to **Global Project Data** and click
    **Plans**.
2.  In the **Plans** dialog box, click the **Calculated Plans** tab.
3.  Click **Add**, and select the plans you want to include in the
    calculated plan (you can also add or remove plans later).
4.  Click **OK**. The new calculated plan is displayed with the default
    name New Calculated Plan.
5.  Edit the name and add a description, if required.
6.  Under **Components**, specify the wedge calculation between the
    plans by editing the factor (a plan with a factor of -1 will be
    subtracted from a plan with a factor of 1, for example).
7.  Add or remove plans, if required, by clicking **Add Plans** or
    **Remove**.
8.  Click **OK**.

You can view the results of calculated plans on the [Reports tab](../../../Generate%20Reports/Reports%20Tab/Generate%20Reports%20on%20the%20Reports%20Tab.md), and in
the [Batch Manager](../../../Generate%20Reports/Use%20the%20Batch%20Manager/Batch%20Manager%20Overview.md).

Calculated plans behave like plans when you run reports.
