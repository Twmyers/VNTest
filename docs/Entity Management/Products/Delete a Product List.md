



# Delete a Product List

You can only delete a custom product list from your project if the
product list is not being used by an entity.

To delete a custom product list from your project

1.  Ensure no entities are using the product list you want to delete.
    

    If required, use the
    [Filter](../../Filter%20Entities/Flag%20and%20Filter%20Entities.md)
    to find any entities using the product list you want to delete.

    
2.  In the **Tools** menu, point to **Global Project Data** and click
    **Products**.
3.  Click the **Product Lists** tab.
4.  In the list on the left, click the product list you want to remove.
5.  Click **Remove**.
