



# Add Entities to a Ring Fence Entity

To add an entity to a ring fence entity (RFE)

1.  In the explorer, right-click the entity you want to add.
2.  Point to **Add to**, and select **Ring Fence**.
3.  In the Add to Entity dialog box, select the Ring Fence and click
    **OK**.



You can also add a Common Termination Entity to a Ring Fence Entity.
