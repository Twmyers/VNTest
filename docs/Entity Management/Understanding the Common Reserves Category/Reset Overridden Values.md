



# Reset Overridden Values

To delete overrides so that values are inherited from another source,
click Reset in the toolbar for each
reserves plan, reserves category, or plan as required.



![](../../Images/Reset-Overridden-Values-1.jpg)



To delete overrides for several entities, in several reserves categories
at once, see
[Remove Inputs](../Plans/Remove%20Inputs.md).

See [Understanding the Common Reserves Category](Understanding%20the%20Common%20Reserves%20Category.md) and
[Override Inherited Values](Override%20Inherited%20Values.md) .
