



# Delete Tabs in Data View

You can only delete a subtab, not a top level tab (Group Tab). However,
if you delete all of a Group Tab’s subtabs, the Group Tab is also
deleted automatically.

To delete a subtab in the
[Switch between the Entity View and Data View](Switch%20between%20the%20Entity%20View%20and%20Data%20View.md) ,
click the X on the tab.
