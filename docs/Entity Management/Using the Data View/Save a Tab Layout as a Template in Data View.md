



# Save a Tab Layout as a Template in Data View

Tab layout determines how the data in the grid is displayed. Layouts
determine which fields are displayed in the rows and columns of the
grid, which data are shown in the grid (as \[Values\]), and which
filters are applied to the data in the grid and within each field.

Once you
[Create and Configure Tabs in Data View](Create%20and%20Configure%20Tabs%20in%20Data%20View.md), you can
save the layout as a template and reuse it or share it with other users.

To save a tab layout as a template in the
[Switch between the Entity View and Data View](Switch%20between%20the%20Entity%20View%20and%20Data%20View.md)

1.  In the top right corner of the layout panel, click **Save As
    Template**.
2.  Under **Location** in the **Save As Template** dialog box, select a
    folder.
3.  If required, click **New Folder** to create a new folder in the
    location you selected.
4.  If required, type a new **Name.**
5.  Click **Save**.
