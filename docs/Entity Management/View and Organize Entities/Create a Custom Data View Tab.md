

# Create a Custom Data View Tab

You can create new sub-tabs (vertical tabs) in Data View to display your
own selection of fields, such as your own custom fields. Custom tabs can
only contain fields from a single input area (such as *Well Info and
Custom Fields* or *Declines*). You cannot combine fields from different
input areas on a single tab.

To create a custom tab

1.  Go to the Data View.
2.  Select the horizontal tab on which you want the new vertical tab to
    be displayed.
3.  Click the black plus sign at the bottom of the vertical tabs.
4.  Select the input field containing the data type you want on your
    custom tab.
5.  In the layout menu on the right, enter a name for the tab.
6.  In the layout menu, right-click and select
    Deselect All.
7.  From the Values list, select the
    fields to display on the new tab.
8.  (Optional) Drag the new tab to any location in the vertical tabs.
