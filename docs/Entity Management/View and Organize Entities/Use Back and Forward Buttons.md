



# Use Back and Forward Buttons

Using the Back and Forward buttons in the toolbar moves you back and
forward through your navigation history. Each time you use the back
button you are returned to your previous context. A context consists of
an entity, tab selection, reserves category, resource category, archive,
and plan. Twenty contexts are saved in your navigation history. Once you
exceed twenty contexts, the oldest context is removed and the most
recent context is added.

- The context list is cleared when you close a project or apply a filter
  to the project.
- The Comparison tab's pinned items are not saved in the navigation
  history.
- Use **Alt + Left Arrow** and **Alt + Right Arrow** for shortcut keys.
