



# Import/Update Actual Costs from Execute

Before importing or updating actuals
fromExecute
, you must configure
Execute
and Value
Navigator integration.

When you import actuals, they are displayed on **Economics \| Prices &
Costs \| Capital Costs** with a green background. Actuals are not
editable in
Value
Navigator and are not used in economic calculations. Actuals
provide information that can be used to make a more accurate capital
cost forecast, which is used in economic calculations.

To display actuals, you must select **Forecasts and Actuals** from the
**View** list in the top left.



If actuals are displayed with a red background, it means the actuals are
not correctly mapped to a
Value
Navigator cost type. Contact your administrator to fix the error.



The blue line indicates the end of actuals. The difference between your
forecasted cost and the actual cost is displayed below **the End of
Actuals** line. This is the suggested forecast. If the suggested
forecast is negative, you have spent more than you forecasted and should
update the forecast to match the actuals.

Economics are run on forecasted capital costs by default (**Run
economics on forecast only** option), but you can run economics on
blended capital costs by selecting **Run Economics on Blended Costs** in
the Project Options, under Economics. See
[Run Economics on Blended Capital Costs](Run%20Economics%20on%20Blended%20Capital%20Costs.md).
