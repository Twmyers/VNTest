



# Filter Entities Overview

You can filter to entities using several methods.

- To filter to entities you have selected in the Entity Explorer, see
  [Filter to a Selection of Entities](Filter%20to%20a%20Selection%20of%20Entities.md).
- To filter to wells you have flagged, see
  [Flag and Filter Entities](Flag%20and%20Filter%20Entities.md).
- To create a filter query, see
  [Create a Filter Query](Create%20a%20Filter%20Query.md).
- To filter to a UWID list you have in a text file or Excel file, see
  [Filter to a UWI List](Filter%20to%20a%20UWI%20List.md).

## Notes on Applying Filters

To clear filters, see
[Clear Filters](Clear%20Filters.md).

When a filter is applied to the project, the **Filter Well List** icon
is red ![](../Images/Filter-Entities-Overview-1.jpg).

If you create entities or edit entity properties that affect the filter
results, the results are not automatically updated. Use the **Reapply
Filter** button (![](../Images/Filter-Entities-Overview-2.jpg)) to update the results.
