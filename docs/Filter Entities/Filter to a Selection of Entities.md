



# Filter to a Selection of Entities

This procedures below explain how to filter your project to the entities
you have selected in the Entity Explorer or in the Data View grid. See
[Using the Data View](../Entity%20Management/Using%20the%20Data%20View/Using%20the%20Data%20View.md).

In the entity hierarchy, you can select a set of entities and/or folders
by using  Shift + right-click or
Ctrl + right-click or dragging your
mouse. On **Wells and General Economics \| Well Infoand Custom Fields**,
you can use the same methods to select entities only.

When a filter is applied to the project, the **Filter Well List** icon
is red ![](../Images/Filter-to-a-Selection-of-Entities-1.jpg).

To filter your project to selected entities in Entity View

1.  In the Entity Explorer, select the entities you want to filter to.
2.  Right-click in the hierarchy and select **Filter to Selection**.

To filter your project to selected entities in Data View

1.  Right-click an entity in the Data View grid.
2.  Select **Filter Hierarchy to Selection**.



If you create entities or edit entity properties that affect the filter
results, the results are not automatically updated. Use the **Reapply
Filter** button (![](../Images/Filter-to-a-Selection-of-Entities-2.jpg)) to update the results.
