

# Filtering Overview

Filters are used to identify entities that are to be acted on in some
like manner. Filter results can be used to create summary reports, to
determine wells to which similar economic parameters will be applied,
and numerous other purposes. There are several options available with
which to select wells in your well list to filter to.

In the entity hierarchy, you can select a set of entities and/or folders
by using  Shift + right-click or
Ctrl + right-click or dragging your
mouse. On **Wells and General Economics \| Well Infoand Custom Fields**,
you can use the same methods to select entities only.



When a filter is applied to the project, the **Filter Well List** icon
is red ![](../Images/Filtering-Overview-1.jpg).



You can filter to entities using several methods.

- To filter to entities you have selected in the Entity Explorer, see
  [Filter to a Selection of Entities](Filter%20to%20a%20Selection%20of%20Entities.md).
- To filter to wells you have flagged, see
  [Flag and Filter Entities](Flag%20and%20Filter%20Entities.md).
- To create a filter query, see
  [Create a Filter Query](Create%20a%20Filter%20Query.md).
- To filter to a UWID list you have in a text file or Excel file, see
  [Filter to a UWI List](Filter%20to%20a%20UWI%20List.md).



If you create entities or edit entity properties that affect the filter
results, the results are not automatically updated. Use the **Reapply
Filter** button (![](../Images/Filtering-Overview-2.jpg)) to update the results.



## Clearing Filters

When you have applied one or more filters, you can clear all of them or
clear only one without clearing the others.

To clear one filter only

1.  On the Standard toolbar click ![](../Images/Filtering-Overview-3.jpg).
2.  Do one of the following:
    | To | Do this |
    |----|----|
    | Clear a filter query, | 1\. Click **Filter Well List**. 2. In the **Filter** dialog box, click **Clear Active Filter**. |
    | Clear a flag filter, | Click **Turn Flag Filter Off**. |
    | Clear a selection filter, | Click **Clear Selection Filter**. |

To clear all filters, click ![](../Images/Filtering-Overview-4.jpg) on the Standard toolbar.



Clearing a filter does not remove manually set flags from entities. See
[Flag and Filter Entities](Flag%20and%20Filter%20Entities.md).
