



# Flag and Filter Entities

You can flag entities in the entity hierarchy or Data View and then
filter to them.



When a filter is applied to the project, the **Filter Well List** icon
is red ![](../Images/Flag-and-Filter-Entities-1.jpg).



In the entity hierarchy, you can select a set of entities and/or folders
by using  Shift + right-click or
Ctrl + right-click or dragging your
mouse. On **Wells and General Economics \| Well Infoand Custom Fields**,
you can use the same methods to select entities only.

To flag and filter to entities

1.  Do one of the following
    1.  Select entities or folders in the entity hierarchy and click
        **Flag Current Hierarchy Selection** ![](../Images/Flag-and-Filter-Entities-2.jpg) in the
        toolbar.
    2.  On **Wells and General Economics \| Well Info and Custom
        Fields** (in Data View), click the check box in the **Flagged**
        column.
    3.  In any of the Data View tabs, select entities, right-click the
        selection, and select Set Flags
        (flags are only visible on **Wells and General Economics \| Well
        Info** **and Custom Fields**.
2.  To toggle the flag filter on and off, click ![](../Images/Flag-and-Filter-Entities-3.jpg) and
    select **Turn Flag Filter On** or **Turn Flag Filter Off**.

If you create entities or edit entity properties that affect the filter
results, the results are not automatically updated. Use the **Reapply
Filter** button (![](../Images/Flag-and-Filter-Entities-4.jpg)) to update the results.

## Clear Flags

Only flags that are saved can be cleared with
Clear All Flags ![](../Images/Flag-and-Filter-Entities-5.jpg). Entities
flagged using the Flag Current Hierarchy
Selection button (![](../Images/Flag-and-Filter-Entities-2.jpg)) are saved automatically.
Entities flagged on **Wells and General Economics \| Well Info and
Custom Fields** are not saved automatically.

To clear all saved flags: On the Standard toolbar, click **Clear All
Flags**.

To clear unsaved flags: Select the entities on **Wells and General
Economics \| Well Infoand Custom Fields**, right-click, and select
**Clear Selected Flags**.
