



# Create Multiple Forecasts on Predictions \| Workspace

**Predictions \| Workspace** enables you to create multiple declines for
an entity. You can then choose whether to apply a decline to a well by
selecting a plan and reserves category. You can also view multiple
forecasts on the same graph for comparison purposes.

The decline you apply to a plan and reserves category is the active
decline. The active decline is displayed with bold text and the Plan and
Reserves Category columns are populated. Edits you make to the active
decline in the **Decline Workspace** are also applied to the decline on
**Predictions \| Declines** and vice versa.

Also see [Create and Edit Declines](../Create%20and%20Edit%20Declines/Create%20and%20Edit%20Declines.md).
