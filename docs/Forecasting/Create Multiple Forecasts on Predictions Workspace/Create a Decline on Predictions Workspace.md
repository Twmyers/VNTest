



# Create a Decline on Predictions \| Workspace

In Entity View, Predictions \|
Workspaceenables you to create unlimited declines on an entity or
group. Only one of the declines on the workspace tab can be active at
any given time. Economics are based on the active decline, which is
displayed on Predictions \| Declines.

Features available on the Workspace tab include:

- Determine which Products and Reserves Categories to view
- Creating declines using Best Fit or Product Cards with Add Forecast
- Editing, copying or deleting existing forecasts
- Apply Forecast to a specified Plan and Reserves Category
- Creating custom labels to attach to declines with Manage Forecast
  Names
- Select Customize Graph with a right-click and modify the rate
  displayed, as well as the x and y axis display settings

When you create a decline on **Predictions \| Workspace**, it is not
automatically applied to a plan or reserves category and only resides on
**Predictions \| Workspace**. You must click
Apply Forecast to make it active.

When you apply a forecast to a plan and reserves category, a copy of the
forecast is made and applied to the new plan. The copied forecast’s name
is the same as the original, but the Plan and Reserves Category columns
are populated and the text is bold. This is the active forecast for the
reserves category and plan and is also displayed on **Predictions \|
Declines** when you select the corresponding reserves category and plan.
The original forecast is still displayed on **Predictions \|
Workspace**, but its text is not bold and the **Plan** and **Reserves
Category** columns are not populated. You can apply the original
forecast to other plans and reserves categories, which always creates a
copy as described above.

To create a decline

1.  Go to **Predictions \| Workspace** and click **Add Forecast**.
2.  Complete the following:
    | Field | Description |
    |----|----|
    | Name | Forecast name |
    | Reserves Category | Select the Reserves Category. |
    | Based On | Only available if you have selected a Reserves Category. Links the forecast to a P/Z analysis or Volumetric analysis. See [Link a Decline to a P/Z or Volumetric Analysis](../Create%20and%20Edit%20Declines/Link%20a%20Decline%20to%20a%20PZ%20or%20Volumetric%20Analysis.md). |
    | Type Well Link | Links to a Type Well’s forecast. |
    | Description | Add a description, if required. |
    | On-time | You can select different on-time types. See [Edit On-Time](../Create%20and%20Edit%20Declines/Edit%20OnTime.md). |
    | 1+WOR | Water Oil Ratio. |
    | GOR | Gas Oil ratio. |
    | RLI | Reserve Life Index. |
3.  Click the decline name (such as Oil or Gas) to display the decline
    calculator. See [Edit Decline Parameters on an Entity](../Create%20and%20Edit%20Declines/Edit%20Decline%20Parameters%20on%20an%20Entity.md) .
4.  Click **Preview in Workspace** to view the new decline in the
    Workspace.
5.  Click **OK**.

The decline is displayed on **Predictions \| Workspace**.

To apply a decline to a plan and reserves category, see [Apply a Forecast to a Reserves Category and Plan](Apply%20a%20Forecast%20to%20a%20Reserves%20Category%20and%20Plan.md).
