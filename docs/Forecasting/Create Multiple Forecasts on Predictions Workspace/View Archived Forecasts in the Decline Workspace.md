



# View Archived Forecasts in the Decline Workspace

On **Predictions \| Workspace**, you can view archived forecasts and
compare them to the active forecast (on **Predictions \| Declines**) or
other forecasts in the decline workspace. Archived forecasts are not
editable.

To view archived forecasts in the Decline Workspace

1.  Go to **Predictions \| Workspace**.
2.  Next to View at the top of the screen, select the Archive(s) you
    want to view. (If you want to compare archived forecasts to the
    Active forecast, also select **Active**.)
