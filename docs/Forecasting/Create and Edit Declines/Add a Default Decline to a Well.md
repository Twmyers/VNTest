



# Add a Default Decline to a Well

For new wells without production history, you can quickly add a default
decline and then edit the parameters on **Predictions \| Declines**.

To add a default decline

1.  On **Predictions \| Declines**, click the plus sign next to the
    decline type you want to add.
    [](../../../Resources/Images/add1.bmp)
2.  Edit the **Start Date** and other parameters as required.
3.  Click the decline name (such as Oil or Gas) to display the decline
    [Calculator](Edit%20Decline%20Parameters%20on%20an%20Entity.md)
    where you can add more segments.
4.  Click ![](../../Images/Add-a-Default-Decline-to-a-Well-2.jpg) to edit or apply the following decline
    options:
    1.  Reserve Life Index
    2.  [Edit On-Time](Edit%20OnTime.md)
    3.  [Set the Start of Forecast](Set%20the%20Start%20of%20Forecast.md)
    4.  [Best Fit or Refit a Decline from a Point](Best%20Fit%20or%20Refit%20a%20Decline%20from%20a%20Point.md)
    5.  [Recalculate a Group Forecast](../../Entity%20Management/Groups%20and%20Rollups/About%20Groups/Recalculate%20a%20Group%20Forecast.md)
    6.  [Set to Current](Set%20to%20Current.md)
    7.  [Apply P/Z or Volumetrics Volumes](Apply%20PZ%20or%20Volumetrics%20Volumes.md)
    8.  [User Options: Units](../../Options/User%20Options/User%20Options%20Units.md)

To change the fields displayed on **Predictions \|Declines**, see [Customize Predictions | Declines Fields](../../Customize%20the%20User%20Interface/Customize%20Predictions%20Declines%20Fields.md).
