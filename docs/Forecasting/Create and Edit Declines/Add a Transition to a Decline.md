



# Add a Transition to a Decline

If a well has a hyperbolic or harmonic decline, you can add an
exponential transition to the end of the decline by clicking **Add
Transition** on **Predictions \| Declines**.

To add a transitions

1.  On **Predictions \| Declines**, select a well with a harmonic or
    hyperbolic declines.
2.  Under the graphs, click the decline you want to edit (such as
    **Gas** or **Oil**) to display the detail view (decline parameters).
    

![](../../Images/Add-a-Transition-to-a-Decline-1.jpg)


3.  To the right of the decline parameters, click **Add Transition**.



You can also press **T** on the keyboard while in
[Decline Editing Hotkey Mode](Decline%20Editing%20Hotkey%20Mode.md) to add a transition.
