



# Best Fit or Refit a Decline from a Selection

Best Fitting or Refitting a forecast from a selection involves selecting
a segment of production history as the basis for the new forecast.
Value
Navigator determines the best forecast based on that selection,
ignoring the history before and after it.

Best Fit and Refit from Selection locks the start and end date for the
fit and does not look at internal segments, except for excluding bad
data.

You can use the following keyboard shortcuts to best fit and refit a
selection:

- Ctrl + B: Changes the cursor so you can
  select the history to use for your forecast and Best Fits the decline.
  Value
  Navigator determines whether the forecast should be hyperbolic,
  harmonic, or exponential based on the history selected.
- Ctrl + Shift + B: Changes the cursor so
  you can select the history to use for your forecast.
  Value
  Navigator uses the current exponent type regardless of the
  history selected.

To Best Fit or Refit a selection of history

1.  On Predictions \| Declines,
    right-click the graph you want to edit.
2.  In the menu, point to the decline type you want to fit and select
    the Fit from Selection option you
    want to perform.
3.  Hold the left mouse button and drag to select the segment of
    production history you want to use.
4.  Release the mouse button.
