



# Draw a Profile

You can create a gas or oil profile by selecting points in the
production history. Once you select the points,
Value
Navigator uses them to create a decline.

To draw a profile

1.  On **Predictions \| Declines**, right click the graph you want to
    edit.
2.  Point to the decline type and select the **Draw**option you want to
    perform.
3.  Click on the points of production history you want to use in the
    decline.
4.  To remove a point, place your cursor near the point and press the
    **Backspace** key.
5.  Do one of the following:
    | To                          | Do this                  |
    |-----------------------------|--------------------------|
    | Cancel the profile,         | Press the **Esc** key.   |
    | Finish drawing the profile, | Press the **Enter** key. |
