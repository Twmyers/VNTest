

# Editing Forecast Parameters on Multiple Wells

Default technical limits for the project are set in [User Options: Product Specific](../../Options/User%20Options/User%20Options%20Product%20Specific.md). However, the
technical limits for wells can be modified for specific forecasts in
Data View on the Predictions Data \|
Declines. For instance, you may wish to modify the final rate
(Qf) for specific gas wells based on their Ultimate Recovery value,
because wells with very high ultimate production may never produce down
to a low Qf before watering out or realizing very high costs.

To set the gas Qf according to the Ultimate Recovery value

1.  Select the top folder in the Entity Explorer.
2.  Change to Data View on the main toolbar.
3.  Select Well Views \| Reserves and
    sort the Ultimate Gas column,
    descending.
4.  Click and drag to select all wells with an Ultimate Gas value
    greater than 1,000 MMcf.
5.  Right-click the selected area and select Set
    Flags.
6.  Click Save changes and filter to flagged
    entities on the Well Views
    toolbar to filter the well list.
7.  Move to Predictions Data \| Declines
    and select only the Gas forecasts using the Product dropdown in the
    Layout Menu on the right side.
8.  Sort the Qf column, ascending. If you
    cannot see the Qf column, scroll to the right.
9.  Change any wells that have a default Qf value of 10 Mcf/d to 50
    Mcf/d, by entering 50 in the first cell, then copying and pasting it
    into the other cells.
10. Click Save changes.
11. Clear the filter with the Clear All
    Filters icon.
12. Clear the flags with the Clear All Flags
    icon.



Clearing the flags will also clear the filter.
