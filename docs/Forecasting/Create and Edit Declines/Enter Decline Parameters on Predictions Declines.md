



# Enter Decline Parameters on Predictions \| Declines

You can create a decline or edit the parameters of a decline on
**Predictions \| Declines**.

Use the buttons below to add or remove declines or decline segments.

| Button | Well Type | Action |
| --- | --- | --- |
| 

![](../../Images/Enter-Decline-Parameters-on-Predictions-Declines-1.jpg)

 | No production history, no forecast | Adds a default decline. |
| Has production history, no forecast | Calculates a forecast. |
| Has a forecast | Adds a segment to the forecast |
| 

![](../../Images/Enter-Decline-Parameters-on-Predictions-Declines-2.png)

 | Any well | Deletes the selected decline segment. |


The symbols below are displayed on **Predictions \| Declines** if the
decline has errors or warnings. See
[Decline Errors and Warnings](Decline%20Errors%20and%20Warnings.md).

| Button | Well Type | Action |
|----|----|----|
| Symbol | Description |   |
| 

![](../../Images/Enter-Decline-Parameters-on-Predictions-Declines-3.png)

 | Warning. Place your mouse cursor over the symbol to see the warning. |   |
| 

![](../../Images/Enter-Decline-Parameters-on-Predictions-Declines-4.png)

 | Error. Place your mouse cursor over the symbol to see the error. |   |

To change the fields displayed on **Predictions \|Declines**, see [Customize Predictions | Declines Fields](../../Customize%20the%20User%20Interface/Customize%20Predictions%20Declines%20Fields.md)
