



# Modify the Inlet or Outlet Gas Analysis on the Plant Tab

To modify the Inlet or Outlet gas analysis on **Predictions \| Data \|
Plant**

1.  Do one of the following:
    | To modify           | Select this Input Mode |
    |---------------------|------------------------|
    | Inlet Gas Analysis  | Raw or Inlet ratios    |
    | Outlet Gas Analysis | Sales ratios           |

    

    When you select an input mode, the corresponding gas analysis is
    highlighted in blue.

    
2.  Edit a value and press **Enter**.

If the total does not equal 100, the Total value is displayed in red.

Three Theoretical Yields are displayed below the analyses. See
[Theoretical Yield](Theoretical%20Yield.md).

See [Add a Gas Analysis](Add%20a%20Gas%20Analysis.md).
