



# Calculate Z Factor

The Z Factor calculator can be used only when you are viewing a gas
well.

To calculate the Z Factor, click **Calc. Z Factor**.

The Z Calculator enables you to calculate the Z factor when entering the
volumetrics data for a gas well.

You can change any of the variables needed to calculate the Z factor. If
you do not wish to change the Z factor, leave the variables as they are.
When you are finished, click **OK**.
