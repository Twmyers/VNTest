



# Exclude a Well from a Type Well

Excluding a well from a type well only excludes its data from the type
well calculation—it does not remove the well (see
[Remove Wells from a Type Well](Remove%20Wells%20from%20a%20Type%20Well.md)). When you exclude
a well, you can easily include it again or choose to remove it entirely
from the type well.

To exclude a well

1.  From the **Entity Type** list in the main toolbar, select **Type
    Wells**.
2.  Select the type well to edit.
3.  On the **Type Well** tab, click the curve of the well you want to
    exclude (or select the well in the Explorer).

Click **Exclude** and then click **Recalculate**.

To include the well again, click **Include** and then click
**Recalculate**.
