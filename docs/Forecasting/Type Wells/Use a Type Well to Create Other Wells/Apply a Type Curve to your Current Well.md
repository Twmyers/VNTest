



# Apply a Type Curve to your Current Well

You can apply a type curve to your currently selected well (or you can
[Batch Apply a Type Curve to Several Wells](Batch%20Apply%20a%20Type%20Curve%20to%20Several%20Wells.md)).
Value
Navigator calculates an appropriate factor to match the well’s
history to the type curve.



You can apply the type curve on **Predictions \| Workspace** and preview
the change (or compare the change to the original decline) before
actually applying the type curve to your well. See [Edit a Decline on Predictions | Workspace](../../Create%20Multiple%20Forecasts%20on%20Predictions%20Workspace/Edit%20a%20Decline%20on%20Predictions%20Workspace.md).



Also see [Update a Well Linked to a Type Well](Update%20a%20Well%20Linked%20to%20a%20Type%20Well.md).

To apply a type well curve to your currently selected well

1.  In the entity hierarchy, select the well you want to apply the type
    curve to.
2.  On **Predictions \| Declines**, click ![](../../../Images/Apply-a-Type-Curve-to-your-Current-Well-1.jpg) and next to
    **No type well link**, click ![](../../../Images/Apply-a-Type-Curve-to-your-Current-Well-2.jpg).
3.  In the **Type Well Link** dialog box, click ![](../../../Images/Apply-a-Type-Curve-to-your-Current-Well-3.png) to
    browse for a source type well.
4.  In the **Add to Entity** dialog box, select the type well and click
    **OK**.
    

    When enabled, the Apply Current
    Filter checkbox applies your current project filter (if any)
    to the Add to Entity window. When
    this checkbox is disabled, your project filter is not applied and
    all entities are displayed.

    
5.  If required, enter a Scaling Factor
    or select a scaling factor calculation method to have
    Value
    Navigator calculate a scaling factor.
6.  Click **Apply** or **OK**.
