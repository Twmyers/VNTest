



# Batch Apply a Type Curve to Several Wells

Use this procedure to apply a type curve to several wells at once.



You can apply the type curve on **Predictions \| Workspace** and preview
the change (or compare the change to the original decline) before
actually applying the type curve to your wells. See [Edit a Decline on Predictions | Workspace](../../Create%20Multiple%20Forecasts%20on%20Predictions%20Workspace/Edit%20a%20Decline%20on%20Predictions%20Workspace.md).



To batch apply a type curve to several wells

1.  From the **Tools** menu, select **Apply/Remove Type Curve**.
2.  Under Options, select **Apply Type Curve** and select **Plans** (to
    apply the changes to your project).
3.  Click ![](../../../Images/Batch-Apply-a-Type-Curve-to-Several-Wells-1.png) to select a source type well from the
     Select Type Well window.
    

    When enabled, the Apply Current
    Filter checkbox applies your current project filter (if any)
    to the Select a Type Well and
    Destination Entitieswindows. When
    this checkbox is disabled, your project filter is not applied and
    all entities are displayed.

    
4.  Under Destination Entities, select the entities you want to apply
    the type curve to.
5.  Select a Scaling Factor option.
6.  Select the **Destination Plans** and **Reserves Categories**.
7.  Click **OK**.

The type curve is applied to the selected wells in the selected reserves
categories.
