



# Batch Remove a Type Curve from Several Wells

Use this procedure to remove a type curve from several wells at once.



You can remove the type curve on **Predictions \| Workspace** and
preview the change (or compare the change to the original decline)
before actually removing the type curve from your wells. See Edit a
Decline on Predictions Workspace.  



To batch remove a type curve from several wells

1.  From the **Tools** menu, select **Apply/Remove Type Curve**.
2.  Under Options, select **Remove Type Well Link.**
3.  Under **Destination Entities**, select the entities you want to
    remove the type curve from.
    

    When enabled, the Apply Current
    Filter checkbox applies your current project filter (if any)
    to the Destination Entitieswindow.
    When this checkbox is disabled, your project filter is not applied
    and all entities are displayed.

    
4.  Select the required **Reserves Categories** and
    Destination Plans.
5.  Click **OK**.

The type well link is removed from the selected entities in the selected
plans and reserves categories.
