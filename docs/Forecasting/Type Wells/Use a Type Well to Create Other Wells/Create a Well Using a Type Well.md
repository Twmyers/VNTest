



# Create a Well Using a Type Well

Type Wells display an averaged representation of the normalized
production history (and forecast, if selected) for a set of wells.
However, this representation is not a decline so you must create a
decline for the Type Well before you can create a new well based on it.

The procedure below explains how to create a decline for a Type Well and
then create a new well with that decline.

To create a well from a Type Well

1.  From the **Entity Type** list in the main toolbar, select **Type
    Wells**.
2.  Select a Type Well and go to **Predictions \| Declines.**
    

    The Type Well’s normalized data is displayed. This is not a decline.

    
3.  Create a decline by [drawing a
    profile](../../Create%20and%20Edit%20Declines/Draw%20a%20Profile.md).
4.  Go back to **Type Well \| Definition** and click **Create Well**.
5.  In the **Well Information** dialog box, complete the following
    options:
    | Tab | Options | Description |
| --- | --- | --- |
| Well Properties | Display Name | Name displayed in the Entity Explorer. |
| Well Name | Well Name |
| Field | Field |
| Field Code | Field Code |
| Pool | Pool |
| Pool Code | Pool Code |
| Country | Select the country. See Add a Country. |
| State/Province | Select the Province or State. See Add a Province or State. |
| County/District | County/District |
| Operator | Operator |
| Licensee | Licensee |
| Unit | Unit |
| Status | Status |
| Scale Factor | Use this factor to scale the well’s production. |
| Start� Date | Use this date to assign the well a forecast start date. |
| Destination Plan | Select a Plans. |
| Destination Reserves Categories | Select a Reserves Category. |
| Reserves Properties | Oil Reserves Type | Standards of disclosure for oil and gas require that products be designated by the type of material being extracted and reserves reports are displayed according to these product types. Select the appropriate oil and gas reserves types. Light and medium oil Heavy oil Bitumen Synthetic oil Shale oil Tight oil |
| Gas Reserves Type | Gas Shale gas Coal bed methane Hydrates Solution gas Synthetic gas |
| Custom Fields | Import Tag | A field used to label wells with custom information. See Configure Custom Fields. |

6.  Click **OK**.

The decline you created for the Type Well is the new well’s decline.
