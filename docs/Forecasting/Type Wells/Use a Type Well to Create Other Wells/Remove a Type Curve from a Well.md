



# Remove a Type Curve from a Well

To remove a type curve from your current well

1.  On **Predictions \| Declines**, click ![](../../../Images/Remove-a-Type-Curve-from-a-Well-1.jpg) and next to
    Type Well Name, click
![](../../../Images/Remove-a-Type-Curve-from-a-Well-2.jpg).
2.  In the **Type Well Link** dialog box, click **Remove**.

The type curve is removed from your current well.

To remove a type well link from several wells at once, see
[Batch Remove a Type Curve from Several Wells](Batch%20Remove%20a%20Type%20Curve%20from%20Several%20Wells.md).
