



# Update a Well Linked to a Type Well

When you have edited a type well’s forecast, you must update any wells
linked to the type well because the new type well forecast is not
automatically applied to any linked wells. The procedure below explains
how to update the type well link for a single well on **Predictions \|
Declines**.

To find all the wells linked to a type well and update all the linked
wells’ forecasts, see [Find and Update Wells Linked to a Type Well](Find%20and%20Update%20Wells%20Linked%20to%20a%20Type%20Well.md).

To update a linked well

1.  Select the well you want to update.
2.  On **Predictions \| Declines**, click ![](../../../Images/Update-a-Well-Linked-to-a-Type-Well-1.jpg) and then click
![](../../../Images/Update-a-Well-Linked-to-a-Type-Well-2.png) next to **Type Well Link**. The Source Type Well is
    displayed.
3.  Click **Apply** to apply the updated type well data to the well.
