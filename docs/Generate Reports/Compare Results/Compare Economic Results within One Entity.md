



# Compare Economic Results within One Entity

Use this procedure to compare results between archives, plans, reserves
categories, or scenarios within an entity.

To compare results within one entity

1.  From the **Comparison** list at the top of **Comparison** **\|
    Economic**, select one of the following: **Cash Flow**, **Costs**,
    or **Production**.
2.  Select a **Currency**, if required.
3.  Select the required **Display Options**.
4.  In the Explorer, select an entity or folder, a reserves plan, plan,
    or calculated plan, and a reserves category.\
    The entity or folder is displayed in bold in the list at the bottom
    of the Comparison tab, prefixed with “Current”.
    

![](../../Images/Compare-Economic-Results-within-One-Entity-1.jpg)


5.  Click **Add Row**.\
    There are now two “Current” entities in the comparison list.
6.  Repeat step 5 to add more current entities.
7.  In the second current entity, change the archive, plan, reserves
    category, or scenario and repeat this step for any other entities in
    the comparison list. The results of the comparison are automatically
    displayed.
    

    If you do not
    [pin](Pin%20Entities%20to%20the%20List%20on%20Comparison%20Economic.md)
    the original “current entity” to the list (right-click the entity
    and select **Pin selection**) it will not be retained when you edit
    the archive, plan, reserves category or scenario of the added rows).

    
8.  **Optional**. Click **Quick Add** to add new rows with the same
    entity, but with different Reserves Categories or Plans, and select
    one of the following two options:
    | Option | Description |
    |----|----|
    | All reserves categories in *\* | Adds all reserves categories with data for the current entity in the current Plan. |
    | \ in all plans | Adds the current reserves category for the current entity in all Plans to the list.  |
9.  **Optional**. Set a row as the [Set a Variance Baseline on the Comparison Tab](Set%20a%20Variance%20Baseline%20on%20the%20Comparison%20Tab.md)the
    **Comparison** Tab.
10. **Optional**. Click the [Play Through Wells](../../Entity%20Management/View%20and%20Organize%20Entities/Play%20through%20Wells.md)in the main toolbar to
    play through all wells. The comparison results are displayed for
    each entity.
