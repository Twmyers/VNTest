

# Compare Results on the Waterfall Chart

On the new Comparison \| Waterfall tab,
you can run a reconciliation on any well or folder and see the
differences against any other version of that well. You can compare
different reserves categories, plans, or archives to see how wells or
fields are changing over time and quickly re-sequence the calculation to
explore sensitivities.

To compare entities or folders

1.  Select the entity or folder you want to compare.
2.  Go to Comparison \| Waterfall.
3.  In the top left under Source, select
    the appropriate Archive, Plan, and Reserves Categories to compare.
4.  On the right, under Content, select
    the scenario or jurisdiction you want to use (or just use the
    project's current options).
5.  Under Display Options, select Gross,
    Working Interest, Company Share, or Net. Then select the product.
6.  Under Sequence, drag and drop items
    to set the order in which you want them calculated.
7.  Click Calculate Graph.

To compare reserves balances with a waterfall chart, see [Compare Reserves Balances on the Waterfall Chart](../../Reserves%20Management/Automated%20Reserves%20Categories/Compare%20Reserves%20Balanaces%20on%20the%20Waterfall%20Chart.md).
