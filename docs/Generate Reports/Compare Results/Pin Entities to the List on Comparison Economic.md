



# Pin Entities to the List on Comparison \| Economic

When you edit the list on **Comparison \| Economic**, it is
automatically updated and all rows that are not pinned to the list are
removed. To retain a row when you edit the selections of other rows, pin
the row to the list.

To pin a row to the list, do one of the following:

1.  Click the pin on the right of the row.
2.  Right-click the row and select **Pin selection**.
