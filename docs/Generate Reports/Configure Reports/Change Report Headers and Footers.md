



# Change Report Headers and Footers

To change report headers and footers

1.  From the **Tools** menu, select **Options**.
2.  In the **Options** dialog box, select the **Project Options** tab
    and then select **Report Headers and Footers** on the left.
3.  Drag **Report Codes** into the **Page Header** or **Page Footer**
    fields and click **OK**.
