



# Change Report Titles

To change the configuration of report titles

1.  From the **Tools** menu, select **Options**.
2.  In the **Options** dialog box, select the **Project Options** tab
    and then select **Report Titles** on the left.
3.  In the top window, delete unwanted codes.
4.  Drag Report Codes, Entity Data Codes, or Custom Field Codes into the
    top window.
5.  Click **OK**.
