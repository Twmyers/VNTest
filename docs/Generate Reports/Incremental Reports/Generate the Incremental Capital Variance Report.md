



# Generate the Incremental Capital Variance Report

The Incremental Capital Variance Report displays the incremental
production between a baseline scenario and another scenario, archive,
plan, or reserves category.

To generate the Incremental Capital Variance Report

1.  From the Tools menu, point to Incremental Reports and select
    Incremental Capital Variance Report.
2.  Complete the following options:
    | Option | Description |
    |----|----|
    | Start Year | Only wells with a production start date in the year specified are included in the report. The report cannot start before the [Economic Calculation Start Date](../../Options/Project%20Options/Project%20Options%20Economics.md#Economic_Calculation_Start_Date). |
    | Months to display | Number of months in the Start Year to be displayed (starting with January). |
    | Maximum hierarchy depth | The number of folder levels to report on. |
    | Baseline scenario | The scenario to serve as a baseline for the incremental report. |
    | Minimum Variance | The minimum amount of variance that will be reported. |
    | Archive | [Archive Data](../../Entity%20Management/Archive%20Data/Archive%20Data.md) for comparison to the Baseline. |
    | Plan | [Plans](../../Entity%20Management/Plans/Plans.md) for comparison to the Baseline. |
    | Reserves Category | Reserves Category for comparison to the Baseline. |
    | Scenario | [Create and Run a Scenario](../Use%20the%20Batch%20Manager/Create%20and%20Run%20a%20Scenario.md) for comparison to the Baseline. |
3.  Click **OK**.
4.  In the Print Preview, select an entity or folder level to view the
    results.

If you do not select **Preview on Selection** in the bottom left of the
Print Preview, report results are not displayed when you select an
entity or folder. To display the results, click **Preview**.

If you select **Preview on Selection**, the report results are
automatically displayed when you select an entity or folder.
