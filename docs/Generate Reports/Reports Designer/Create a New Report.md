



# Create a New Report

A new report is one you build from scratch and is not based on an
existing report. To use a default report as the source of a new report,
see
[Create a Report Copy](Create%20a%20Report%20Copy.md)

To create a new report

1.  In the toolbar, click the **Select/Manage Reports** icon
![](../../Images/Create-a-New-Report-1.jpg).
2.  Under Available Reports, click **Create** and select either **Report
    in Report Designer** or **Report in Custom Reporter**.

See [Create a Report in the Report Designer](Create%20a%20Report%20in%20the%20Report%20Designer.md) or see
Custom Reporter.
