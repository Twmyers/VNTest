



# Enable or Disable Unit Scaling on Reports

To disable unit scaling on reports

1.  Click the options icon (![](../../Images/Enable-or-Disable-Unit-Scaling-on-Reports-1.jpg)) on the **Reports** tab or
    in the Print Preview.
2.  Select Force all auto-scaled values in reports to use standard
    units.

When the **Force all auto-scaled values…** option is not selected**,**
the unit used is determined from the maximum value in the column(s).
This means the units used could be different for each report.

When the **Force all auto-scaled values…** is selected, a standard unit
(Mbbl, MMcf, bbl/d, Mcf/d, etc...) is used regardless of the maximum
value in the column(s). This means the units used are consistent in all
reports.

The **Force all auto-scaled values…** checkbox has no effect on values
that are not auto-scaled.
