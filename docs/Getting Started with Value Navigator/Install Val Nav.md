

# Install Value Navigator

This topic explains how to install any version of
Value
Navigator from 2018 or later. See
[Hardware and Software Requirements](Hardware%20and%20Software%20Requirements.md) before you
install.

To download the installation files, go to the
Value
Navigator Client site at [https://clients.aucerna.com/](https://clients.aucerna.com/). If you don't have an
account, contact
[Value Navigator Support](../../Support.md).

Ensure you have an internet connection for your initial launch of
Value
Navigator. You might need to enter your new product key and must
have an internet connection to validate it. If you are upgrading from a
previous version of
Value
Navigator, a new product key is not required.
Value
Navigator will detect the product key currently in use. If you
don't need a product key, contact your administrator or contact
[Value Navigator Support](../../Support.md).

Value Navigator (2018 and later) is compiled only in a 64 bit version.
The 64 bit version can only be installed on computers with 64 bit
operating systems. Please ensure you have a 64 bit operating system
before installing
Value
Navigator. To check your machine, open File Explorer, right-click
This PC on the left, and select
Properties.

When you install
Value
Navigator, it is available to all users of the computer.

Any beta versions of
Value
Navigator are automatically replaced with the release version.
Previous versions of
Value
Navigator can remain installed.

To install
Value
Navigator

1.  Download the
    Value
    Navigator.zip file from
    [https://clients.aucerna.com/](https://clients.aucerna.com/) and save it to your
    local drive or a network drive.
2.  Extract the files from the zip file. The extracted folders contain
    additional documents that you may find useful when using
    Value
    Navigator.
3.  Before beginning the installation, ensure that all other programs
    are closed and that you have Administrator rights on your machine.
4.  Double-click the Value
    Navigator.x64.exe file in the extracted Installation folder
    to start the installer.
5.  Follow the installer instructions.
6.  Reboot your computer, if requested.
7.  Double-click the
    Value
    Navigator icon on the desktop. For Windows 7 installations
    only, you may need to right-click the desktop shortcut and Run as
    Admin the first time you connect to the license to ensure the
    required access permissions are granted.
8.  If prompted, enter the Product Key. See
    [Activate a License](Licensing/Activate%20a%20License.md).

When you open a
Value
Navigator project from an older version, it is automatically
upgraded and a back up is created (except SQL Server or Oracle
Projects). See [Upgrade Value Navigator Projects](Upgrading%20to%20Value%20Navigator%202021.md).
