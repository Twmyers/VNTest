

# Licensing Overview

Value
Navigator
2026 uses a
cloud-based licensing system. Previous versions use a separate,
file-based license system. The licenses you have for versions prior to
version 2016 will expire and not be renewed unless you request it. You
can run file-based or cloud-based
Value
Navigator versions simultaneously.

With cloud-based licenses, you need to enter a product key when you
first install
Value
Navigator. All users at a company use the same product key. When
a you log in, the application polls the licensing server to determine if
there are licenses available. If you don’t know your product key,
contact your administrator or contact
[Value Navigator Support](../../../Support.md).

Licenses are concurrent. When you use
Value
Navigator, you subtract one license from your company’s pool of
available licenses. It is best to close
Value
Navigator when you are not using it in order to free a license
for other users.

Cloud-based licensing is dependent on an internet connection, but a you
can [request to work offline](Work%20Offline.md). However, working
offline subtracts a license from your company’s total available license
count even when you're not using
Value
Navigator.

There is some allowance for an intermittent internet connection so you
don’t lose your connection to the license due to a brief disconnection.

In order to access the Value Navigator licensing server, you must
ensure:

- Firewall rules allow connection to licensing.energynavigator.com with
  access on port 443.
- Anti-virus software allows
  Value
  Navigator to access the internet
- Your system date and time is correct
