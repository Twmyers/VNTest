

# Troubleshoot License Errors

The table below summarizes common licensing errors, causes, and
solutions.

| Error | Cause | Solution |
| --- | --- | --- |
| “Cannot acquire a license” message | No internet connection. | Reconnect to the internet. |
| Computer time and/or date are incorrect. Even being off by a few minutes might cause this error. | Correct the system time. |
| The firewall or other security is preventing contact with the licensing server. | Contact your IT administrator. |
| “License has been revoked” message | License has expired | Contact Value Navigator Support. |
| License limit reached but no one seems to be using the application | One or more users are logged in to the application (but gone on vacation, home sick, etc.). | Use the License Portal to view active sessions (and release them, if required) . |
| The application did not shut down properly on another user’s machine and is running in the background. | Use Task Manager to shut down the application or restart the computer. |
