

# Value Navigator Configuration

The topics below explain configuration options for the application and
economics service configuration files. The following configuration
options can be edited by application administrators to optimize some
work flows. The options are listed in the order they are found in the
files.

The default configuration files are suitable for most implementations of
Value
Navigator in a local workstation setting. They should only be
modified in order to optimize for specific requirements.

The configuration files are editable in a text editor and are found in
the install directory for the application,
usually:C:\Program Files\Energy Navigator\Value
Navigator \.

 

See [ENI Value Navigator EXE Config](ENI%20Value%20Navigator%20EXE%20Cconfig.md) and
[ENI Value Navigator Economics Service Host Config](ENI%20ValueNavigator%20Economics%20Service%20Host%20Config.md).
