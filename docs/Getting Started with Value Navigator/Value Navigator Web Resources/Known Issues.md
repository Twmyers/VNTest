



# Known Issues

If you are connecting to an Access database to import External Data into
Value
Navigator, you will not be able to do this with the 64-bit
installation. 64-bit compile will not support connections to Access
currently. If you run into this issue, please contact Support and let
them know to pass this on to Development so we can determine if a fix is
required for this issue in future releases of
Value
Navigator.

Please check[https://clients.aucerna.com/](https://clients.aucerna.com/), for updates on this
and other important information.

Value
Navigator issues known to Energy Navigator are investigated,
documented, and posted on our website to ensure that users are aware of
issues that might affect their work flow. You require a user name and
password (available from ) to view the Known Issues.

If you already have a user name and password, log
into[https://clients.aucerna.com/](https://clients.aucerna.com/) to see the Known
Issues.
