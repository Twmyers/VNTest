



# Delete Graph Comments

You can delete graph comments on the graph or on
Info \| Comments (if you want to delete
in bulk).

To delete a comment on a graph

1.  Right-click the comment, point to **Graph Comments**, and click
    **Delete Comment**.
2.  Click **Yes**.

To delete a comment on Info \| Comments

1.  Go to Info \| Comments.
2.  Select the comment(s) you want to delete.
3.  Click Delete.
