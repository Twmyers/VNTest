



# Edit Graph Comments

You can edit graph comments on the graph or on
Info \| Comments.

On the graph, you can edit the text, text color, graph series, or set a
new series value.

On Info \| Comments, you can edit the
text, comment type, reserves category or [link a
document](../../Entity%20Management/Create%20and%20Edit%20Wells/Link%20Documents%20to%20an%20Entity.md)
to the comment.

To edit comments on a graph

1.  Move your mouse over the comment you want to edit (for line
    annotations, move your mouse over the line). The mouse pointer turns
    into a hand.
2.  Right click the comment, point to **Graph Comments** and select
    **Edit Comment**.
3.  Edit the comment text or other parameters.
4.  Click **OK**.

To edit comments on Info \| Comments

1.  Select the entity the comment is attached to.
2.  Go to the **Info \| Comments** .
3.  Double-click the comment row or click **Edit**to open the **Comment
    Editor**.
