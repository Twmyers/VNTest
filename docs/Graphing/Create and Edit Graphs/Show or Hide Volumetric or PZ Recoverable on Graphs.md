



# Show or Hide Volumetric or P/Z Recoverable on Graphs

All default graphs are read-only, but you can make copies of the graph
and edit its options.

To show or hide Volumetric or P/Z recoverable on a graph

1.  On **Predictions \| Declines** or **Predictions \| Volumetrics**,
    right-click any graph and click **Select/Manage Graphs**.
2.  In the Select/Manage Graphs dialog box, click the report you want to
    make a copy of and click **Edit**.\
    The Graph Version Manager is displayed.
3.  Select the graph version you want to copy and click **Edit**. \
    “This graph is read-only. Would you like to edit a copy” is
    displayed.
4.  Click **Yes**.\
    The Graph Designer is displayed.
5.  In the Graph Designer, click ![](../../Images/Show-or-Hide-Volumetric-or-PZ-Recoverable-on-Graphs-1.jpg).
6.  For Volumetrics recoverable or P/Z recoverable, select **Hide** or
    **Show**.
7.  Click **Save**.
8.  Enter a name for new graph.
9.  Close the Graph Editor and Graph Version Manager and select the new
    graph in the Select\Manage Graphs dialog box.
10. Click **OK**.
