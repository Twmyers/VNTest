

# Control Graph Log Cycles

For more consistent data display on graphs, you can set the number of
log cycles in custom graphs (graphs you create or copies of existing
graphs).

For a full description of creating graphs, see [Create and Edit Graphs](../Create%20and%20Edit%20Graphs/Create%20and%20Edit%20Graphs.md).

To set the number of log cycles

1.  In the graph editor, select Region on
    the left.

2.  On the right, select Force log axes
    and enter the number of cycles.
