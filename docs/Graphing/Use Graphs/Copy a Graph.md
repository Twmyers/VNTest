



# Copy a Graph

Any graphs that you create in
Value
Navigator can be exported from the program as a graph or as a
table. When you copy a graph as an image, the image of the graph remains
on your clipboard and can be pasted into other programs. When you copy a
graph as a table, the information from the table is added to the
clipboard as a table that can be pasted into spreadsheet applications.

To create a copy of a graph that you can edit, see
[Create a Graph Copy](../Create%20and%20Edit%20Graphs/Create%20a%20Graph%20Copy.md) .

To copy a graph

1.  Right-click the graph you want to copy.
2.  Do one of the following:
    | If | Then |
    |----|----|
    | You selected **Copy as Image**, | Open a word processor or graphics program and press **Ctrl+V** on the keyboard. |
    | You selected **Copy as Table**, | Open a spreadsheet program, such as Excel, and press **Ctrl+V** on the keyboard. |



With stacked graphs, the stacked values are copied. For gas wells, gas
is at the bottom, then oil, and then water. For oil wells, oil is on the
bottom, then gas, then water.
