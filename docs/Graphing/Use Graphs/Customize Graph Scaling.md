



# Customize Graph Scaling



The [Auto-scale to the Start of
Forecast](Scale%20Graphs%20to%20the%20Start%20of%20Forecast.md) setting
takes precedence over any custom x-axis scaling.



Also see
[Control Graph Log Cycles](Control%20Graph%20Log%20Cycles.md) and [Set the Number of Months Displayed before and after the Start of Forecast](Set%20the%20Number%20of%20Months%20Displayed%20before%20and%20after%20the%20Start%20of%20Forecast.md)

## Quick Graph Scaling on Predictions \| Declines

On Predictions \| Declines, you can
customize graph scaling in two ways, as described below. Method 1 takes
precedence over Method 2.

### Method 1: Quick Graph Scaling

To set custom scaling directly on the
Predictions \| Declines graphs, click the
axis values as described below.

- **Double-click**: Set axis maximum scale
- **Shift + double-click**: Set axis minimum scale
- **Middle-click**: Reset scaling on single axis
- **Shift-Z**: Reset all quick scaling



 

#### Reset Quick Graph Scaling

You can reset quick graph scaling on a graph with
Shift + Z. If you are also using Method 2
above, resetting quick graph scaling reverts you to the Method 1 scaling
values.

### Method 2: Custom Scaling in Graph Options

Scaling set using Method 1 takes precedence over Method 2. If you are
using both methods and then reset the Method 1 values, the graphs revert
to the Method 2 values.

To use custom scaling

1.  Right-click a graph on **Predictions \| Declines** and select
    **Graph and Scaling Options**.
2.  Select **Use Custom Scaling**.
3.  Do one of the following:
    | Select | And |
    |----|----|
    | Custom X Axis Scaling, | In the **Scaling Mode** column, select **Manual** for the products you want to customize. Enter a **Minimum** and **Maximum** value. |
    | Custom Y Axis Scaling, | For each item, enter a maximum value and select **Use Custom Scaling** or click **Calculate From Well**. |
4.  Click **OK**.

## Axis Scaling on Predictions \| P/Z

Use **Method 2**, above.
