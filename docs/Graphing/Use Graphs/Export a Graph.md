



# Export a Graph

You can export graphs in .csv, .html, or .pdf formats.

To export a graph

1.  Right-click the graph and select **Print Graph**.
2.  In the **Print Preview** click **Export** ![](../../Images/Export-a-Graph-1.png).
3.  Browse to a location and enter a name for the graph.
4.  In the **Save as type** list, select the format you want to use and
    click **Save**.
