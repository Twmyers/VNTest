



# Print a Graph

To print a graph

1.  Right-click the graph and click **Print Graph**.
2.  Do one of the following:
    | To | Do This |
    |----|----|
    | Print the graph with the current print settings, | Click ![](../../Images/Print-a-Graph-1.png). |
    | To edit the print settings (page size, orientation, etc.), | Click ![](../../Images/Print-a-Graph-2.png). |
    | Change the units on the graph, | Click ![](../../Images/Print-a-Graph-3.png). |
    | Export the graph as .pdf, .csv, or .html, | Click ![](../../Images/Print-a-Graph-4.png). |
