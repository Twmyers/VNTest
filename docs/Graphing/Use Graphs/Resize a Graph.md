



# Resize a Graph

You can resize graphs on **Predictions \| Declines** or **Predictions \|
Status** by using the **Graphing** toolbar. The table below describes
the function of each button on the toolbar.

| Button | Name | Description |
|----|----|----|
| 

![](../../Images/Resize-a-Graph-1.jpg)

 | Maximize Width | Expands the width of the selected graph. |
| 

![](../../Images/Resize-a-Graph-2.png)

 | Maximize | Expands the selected graph to full size. |
| 

![](../../Images/Resize-a-Graph-3.png)

 | Restore | Restores both graphs to their original size. |
