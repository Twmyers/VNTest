

# Scale Graphs to the Start of Forecast

To scale graphs to the start of forecast

1.  On Predictions \| Declines, click the
    graph you want to scale.
2.  Right-click and select Auto-scale to the
    start of Forecast.



When using Auto-scale to the Start of Forecast, it takes precedence over
any manually set graph scaling.



When using Auto-scale to the Start of Forecast, you can set how many
months are displayed before and after the start of forecast date. See [Set the Number of Months Displayed before and after the Start of Forecast](Set%20the%20Number%20of%20Months%20Displayed%20before%20and%20after%20the%20Start%20of%20Forecast.md).
