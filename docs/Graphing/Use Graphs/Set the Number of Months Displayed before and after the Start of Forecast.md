

# Set the Number of Months Displayed before and after the Start of Forecast

On Predictions \| Declines graphs, you
can set the number of months before and after the start of forecast.

This setting is only used when a graph is set to auto-scale to the start
of forecast. See
[Scale Graphs to the Start of Forecast](Scale%20Graphs%20to%20the%20Start%20of%20Forecast.md).

To set the number of months displayed before and after the start of
forecast

1.  On Predictions \| Declines, click the
    graph you want to scale.
2.  Right-click and select Graph and Scaling
    Options.
3.  On the General tab, under
    General Options, enter the number of
    before and after months.
