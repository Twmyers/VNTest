



# Configure an External Data Source

Before you can import or update  monthly production (using PPDM), daily
data (using your corporate data hub), or actual capital costs from
Execute,
you must configure the IHS, GeoLogic, Daily Data, or AFE .vnudl file
settings in
Execute.

This procedure requires a vnudl file. See [Create a .vnudl file to connect to an Oracle database](Create%20a%20vnudl%20file%20to%20connect%20to%20an%20Oracle%20database.md).

To configure an external data connection

1.  On the **Tools** menu, click **Options**.
2.  On the **User Options** tab, click **Data Sources**.
3.  From the **Profile** list, select **GeoLogic**, **IHS**, Daily
    **Data**, or **Actual Capital Costs (AFENav)**.
4.  In the **Connection** field, click ![](../../Images/Configure-an-External-Data-Connection-1.jpg).
5.  Browse to the **.vnudl** file you want to use and click **Open**.
6.  Click **Validate** to test the connection.
7.  Click **OK**.

If the validation is not successful, try another .vnudl file or contact
your administrator.



Ensure the data you want to import is selected under **Data to Import**
in [User Options: External Data Settings](../../Options/User%20Options/User%20Options%20External%20Data%20Settings.md) .
