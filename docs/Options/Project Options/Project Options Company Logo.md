

# Project Options: Colors and Logo

You can specify a company logo (bmp, .png, .jpg) to be displayed on
reports, as well as the **Logo Position**, **Current Data Colour** and
**System Scenario Colour**. Images are resized automatically, if
required.

See [Add (or Remove) a Company Logo to Reports](../../Generate%20Reports/Configure%20Reports/Add%20or%20Remove%20a%20Company%20Logo%20to%20Reports.md).
