



# Project Options: Reserves

Automated reserves reconciliation (ARR) is enabled by default in any
project created in Value Navigator 2018 or later (you can still create
change records manually). However, ARR is not enabled by default in any
project upgraded to Value Navigator 2018 or later. For upgraded
projects, you must enable ARR in the project options.

See [Automated Reserves Reconciliation Overview](../../Reserves%20Management/Automated%20Reserves%20Categories/Automated%20Reserves%20Reconciliation%20Overview.md).

The settings below are now set by jurisdiction and have been moved to
the Jurisdictions dialog box. See [Create Jurisdictions](../../Reserves%20Management/Jurisdictions/Create%20Jurisdictions.md).

- Reserves price deck
- Reserves categories included in balancing
- Only allow balanced entities to be promoted
