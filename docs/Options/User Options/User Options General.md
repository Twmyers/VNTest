



# User Options: General

## Reserves Category Display During Entity Selection

**Keep current reserves category**: The selected reserve category is
displayed for each entity (well or folder) you select in the Entity
Explorer. This enables you to keep viewing the same reserve category
regardless of the well or folder you select.

**Select first reserves category with data**: The first reserve category
with a decline or economic case is displayed when you select a well or
folder in the Entity Explorer.

## Play Delay (ms)

This option determines the play back speed (in milliseconds) when using
the play button in the Controller Toolbar. See [Play Through Wells](../../Entity%20Management/View%20and%20Organize%20Entities/Play%20through%20Wells.md).

## Use Sparse Reporting Logic

This option only applies to reports in the Batch Manager. It does not
apply to reports on the **Reports** tab.

**Enabled**: Only reports for entities or folders where forecast and/or
economic data exist will appear in the Print Preview.

**Disabled**: All reports will appear in the Print Preview, even if they
do not have data to display.

## Decline Display Settings

Value

- Show nominal rates
- Show effective rates (tangent)

## Reset Suppressed Warnings

This button enables warnings that were previously turned off.
