

# User Options Overview

User Options are user specific, which means your options are used any
time you open a
Value
Navigator project. If another user opens your project, their user
options are applied.

User options control file locations, report settings, and display
settings, and unit settings. But they also control import and fit
settings that are critical to production import and forecasting
behaviour. Therefore, it is critical for consistent production and
forecasting that all users have the same user settings.
