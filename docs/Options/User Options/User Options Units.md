



# User Options: Units

These settings determine the default display of units throughout
Value
Navigator (except reports).

For example, if you select **bbl** for Oil, the Qi and Qf on
**Predictions \|Declines** will be displayed in barrels.  

You can access the unit option on **Predictions \| Declines** by
clicking ![](../../Images/User-Options-Units-1.jpg) and selecting **Unit Options**.
