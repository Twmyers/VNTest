

# Delete Production Data Plug-in

The Delete Production Data plug-in enable you to delete production data
that might have been entered in error.

Please contact [Val Nav Support](../../Support.md) to request the
plugin. The plugins are version-specific, so please include your version
of Val Nav in your request.

To install a plug-in see
[Download and Install Plug-ins](Install%20Plug-ins.md).



You require the Reserves Administration security policy to run this
plug-in.



To use the plug-in

1.  Select a well or folder from the entity hierarchy, depending on what
    production you need to delete. If you select a folder, the
    production as selected in the tool will be deleted from all wells in
    the folder.
2.  Go to Administration \&gt;
    Data Cleanup \&gt;
    Delete Production Data.
3.  Select the appropriate option for the dates of production data to be
    deleted.
4.  If desired, select Apply to child entities
    to delete production from the children of the groups.
