

# Delete Production Data

The Delete Production Data tool is available from the **Administration
\&gt; Data Cleanup** menu.



You require the Reserves Administration security policy to delete
Production Data.



To use the plug-in

1.  Select a well or folder from the entity hierarchy, depending on what
    production you need to delete. If you select a folder, the
    production as selected in the tool will be deleted from all wells in
    the folder.
2.  Go to Administration \&gt;
    Data Cleanup \&gt;
    Delete Production Data.
3.  Select the appropriate option for the dates of production data to be
    deleted.
4.  If desired, select Apply to child entities
    to delete production from the children of the groups.
