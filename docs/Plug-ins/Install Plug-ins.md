

# Download and Install Plug-ins

Plug-ins are available from the Plug-Ins folder included in the Val Nav
installer files downloaded from the Client Portal. If the required
plug-in is not in that folder, please contact
[Value Navigator Support](../../Support.md).

Plug-ins are only offered in a 64 bit version. They are also version
specific so ensure the plug-in is saved in the version folder that
matches the version of
Value
Navigator you want to use. When you install a plug-in, the
plug-in is saved in your plug-ins folder, located here by
default: C:\Program Files\Energy
Navigator\\Value
Navigator*\*\Plugins. In Val Nav 2021 V2 and later, the
folder is located here: C:\Program Files\Quorum Software\Value
Navigator\\Plugins.

To install a plug-in

1.  Close Value
    Navigator. If you install the plug-in while
    Value
    Navigatoris open, you'll need to close it and open it again
    to load the plug-in.

2.  Double click the plug-in .msi file and follow the wizard.

3.  Ensure you install the plug-in in the plug-in folder of your current
    Value
    Navigator installation or in the folder of the ValNav version
    that matches the plug-in version.

    

     

4.  Open Value
    Navigator and select the plug-in from the
    Plug-ins menu.
