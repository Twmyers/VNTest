

# Schedule Adjustment Plug-in

The Schedule Adjustment Plug-in time shifts the forecast start date,
sets of capital costs, and sets of operating costs. It shifts these
values across reserves categories on the Working plan, and maintains the
time relationships between costs. Forecast start dates and operating
costs are shifted relative to the New Forecast Start Date that you set.
Capital costs are shifted relative to the New First Capital Date.

When you execute the adjustment schedule, a row for every reserves
category to be adjusted is displayed, including the Base reserves
category in some cases. Base is displayed when the entity has no capital
costs. The operating costs on Base will be adjusted relative to the
current forecast date even though Base never has a forecast.

This plug in loads forecast and cost data for every reserves category
for every you specify. It might take some time to process a large list
of wells.

Please contact Val Nav support to request the Schedule Adjustment plugin
for your version of Val Nav.

To install a plug-in see
[Download and Install Plug-ins](Install%20Plug-ins.md).



You require the Edit Entity security policy to run this plug-in.



To use the plug-in

1.  In ValNav, select the plug-in from the
    Plug-ins menu.
2.  Enter, paste or import the UWIs you want to edit.
3.  Select, paste or import a date for
    Adjustment First Capital and
    Adjustment Forecast Start.
4.  In the Use column, select all the
    entities you want to adjust.
5.  Click the Adjustment Schedule tab.
    The adjusted schedule is displayed.
    

    You can override dates by clicking a cell.

    
6.  Click  Execute Adjustment Schedule.
