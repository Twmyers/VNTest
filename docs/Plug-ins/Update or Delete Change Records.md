

# Update or Delete Change Records

This tool enables you to view all current change records in a Value
Navigator project and edit or delete them in bulk. If a change record
was created in a batch, you cannot edit/delete portions of the batch.
You must change/delete the entire batch at once.

The Update/Delete Change Records tool is available from the
**Administration \&gt; Data Cleanup** menu.



You require the Reserves Administration security policy to Update or
Delete Change Records.



To use the plug-in

1.  In ValNav, select the plug-in from the
    Plug-ins folder. The Update/Delete
    Change Records dialog appears with a list of all change records
    currently active in the project. Change records that were created in
    a batch are listed in one row with an entity count to reflect the
    number of entities that have that change record applied.
2.  Do one of the following:
    | To | Do this |
    |----|----|
    | To delete a change record (or a batch), | Select the Delete check box beside the batch (or batches) you want to delete, and click Delete. |
    | To edit a change record (or a batch), | Select new values for any of the columns with the editable column header and select Yes to confirm the change. |
