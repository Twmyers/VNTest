



# Create a Price Deck

To create a new price deck, you have two options: create one from
scratch or create a copy of a price deck that is similar to the new one
you want to create. Creating a copy is significantly easier because you
don’t need to edit all of the price deck attributes (such as royalties
and tax rates).  We strongly recommend copying and modifying an existing
price deck, as described below.

To copy and modify a price deck

1.  In the **Tools** menu, select **Global Project Data \&gt; Price
    Decks**.
2.  Next to **Select Price Deck**, select the price deck you want to
    copy.
3.  To the right of the **Select Price Deck** list, click **Copy**.
4.  Enter a name for the new price deck and click **OK**.
5.  Create or edit the [stream price](Create%20a%20Stream%20Price.md) and
    [exchange rates](Edit%20Exchange%20Rates.md),
    and [create price sets](Create%20a%20Price%20Set.md),
    as required.
6.  To the right of the **Select Price Deck** list, click **Make
    Active** to apply the price deck to your project.
7.  Click **OK** in the **Price Deck Editor**.
