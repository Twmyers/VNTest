



# Create a Price Set

Wells rarely produce only oil or only gas. A
Value
Navigator Price Set is a customized collection of stream prices,
one for each product, usually at gas delivery points or for a battery or
property that produces a certain quality of oil. You can use price sets
from evaluator’s price decks, or create your own custom price sets to
apply to an entity or a set of entities. Price sets can be different for
each entity, or you can select a price set for one well and then copy to
other wells in the project using the Input Copier. Price Sets are
created in a Price Deck, but selected at the individual well level.

The currently applied price deck and price set are displayed in Entity
View on Economics \| Prices & Costs \|
Prices.

Before creating a price set, you must create each of the stream prices
you want to include in it. See
[Create a Stream Price](Create%20a%20Stream%20Price.md) .

To create a price set

1.  In the **Tools** menu, select **Global Project Data** \&gt;**Price
    Decks**.
2.  In the Price Deck Editor, click **Price Sets** (on the left).
3.  In the editor window, select the folder level where you want the new
    price set.
4.  Under the Price Set window, click **Add**.
5.  Enter a name and click **OK**.
6.  To the right of the Price Set window, specify the Country and
    Province/State, (these fields are already selected if you chose the
    appropriate folder level).
7.  Under Prices, select a stream price for each product.
8.  Click **Save** and OK.
