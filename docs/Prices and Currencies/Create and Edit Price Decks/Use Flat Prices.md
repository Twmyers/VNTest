



# Use Flat Prices

To use flat Prices, download the
Value
Navigator Flat Price Decks from
[https://clients.aucerna.com/](https://clients.aucerna.com/).

To use the Flat price deck

1.  [Import and Export Price Decks](../Manage%20Price%20Decks/Import%20and%20Export%20Price%20Decks.md)the Flat price
    deck and make it active.
2.  In the deck, click **Stream Prices** on the left.
3.  Edit the **Flat Oil** or **Flat Gas** prices only. All other prices
    are linked to these two prices.
