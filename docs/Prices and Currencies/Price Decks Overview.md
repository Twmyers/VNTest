

# Price Decks Overview

The Price Deck is global and applies to all entities in the project.
Sales Prices, Royalty Prices, Inflation Rates, Tax Rates and Exchange
Rates are all available in the price deck. You can use an evaluator’s
price deck, or build your own.

Price Files for use in
Value
Navigator are posted on our website quarterly. We supply price
files from the following evaluators: Mc Daniel, Sproule, GLJ, Deloitte,
Trimble, and Ryder Scott. We also post a Flat price deck. The price
decks supplied by the evaluators are converted to \*.xml format.

To access the price files you need a user name and password to log into
the secure area of our website. To receive a user name and password,
please contact
[Value Navigator Support](../../Support.md).

If you already have a user name and password, log into
[https://community.quorumsoftware.com](https://community.quorumsoftware.com/) and search for
Price Files.

To import a price deck

1.  Download the price deck and save it to your local disk or a network
    drive, or request the path to the price file from your
    Value
    Navigator Administrator.
2.  From the File \&gt;
    Import menu, select
    File…
3.  In the Import dialog box, select Import
    from an existing file, then click the ellipsis in the
    File field.
4.  Browse to the .xml price file you want to import and click
    Open.
5.  Click Next to display the data that
    will be imported.
6.  If asked to upgrade the xml file, click
    OK.
7.  Click Finish to import the price
    deck(s).
8.  Once your price deck has been imported, it needs to be activated to
    see the prices in
    Value
    Navigator.

To activate a price deck

1.  Open the Price Deck Editor from Tools
    \&gt; Global Project Data \&gt;
    Price Decks or by clicking
    Edit Price Decks on
    Economics \| Prices & Costs \|
    Prices.
2.  Select a price deck from the Select Price
    Deck list at the top left of the Price Deck Editor window.
3.  Click Make Active to enable the price
    deck, then click OK to close the
    Price Deck Editor.



You may need to select a new price set on the entity level after
changing to a different price deck.
