

# 2016 v1.1 Release Notes

## Schema Changes

There are a few minor changes to support the new MRF royalty data. See
the Database Administration folder of the release package for more
details of these changes.

## Modernized Royalty Framework

Value
Navigator 2016 v1.1 builds upon the Modernized Royalty Framework
functionality released in
Value
Navigator 2016. Please see the release notes for that version;
this list of changes is supplemental:

- The gas maturity threshold is now in place in the post-C\* calculation
- New well-level properties for Total Proppant Placed, Acid-Fracture
  Volume, Completion Type, and Acid Concentration (Data View \&gt; Wells
  and General Economics \&gt; Well Info and Custom Fields)
- MRF production categories have not changed from
  Value
  Navigator 2016 (Modernized & ARF to Modernized)
- There are now four MRF incentives:
  - Modernized: the standard incentive for 2017 and later wells; has C\*
    & related fields
  - Enhanced Hydrocarbon Recovery (MRF): for wells in the EHRP program;
    has C\* and an allowable number of months of program eligibility
  - Enhanced Oil Recovery (MRF New Drill): for new drills into an older
    EORP scheme; has C\* and allowable months; will terminate the
    incentive Dec 31, 2026
  - Emerging Resources Program (MRF): for use with wells in a ring
    fence; has C\*, C\* multiplier, and resultant C\*ERP
- On the interests & royalties tab, for Alberta wells, are all the
  C\*-related well-level fields (proppant placed, acid volume, etc) for
  quick review/edit
- All incentives now have a balance effective date, to allow for future
  economic calculation date changes
- Exclusive to VN 2016 v1.1: Emerging Resources Program
  - To calculate this advanced program, you need to add your
    program-eligible wells to a ring fence
  - Be aware of the ‘Preserve regime properties on existing entities’
    option – if you have already set up the incentives on the wells, you
    need to check this option to ensure that incentive is retained
  - Ensure the ring fence is in Canada/Alberta
  - There is a new Calculation field on the ring fence tab – select
    Emerging Resources Program
  - Ensure all the child wells have the Emerging Resources Program (MRF)
    incentive and C\*ERP populated
  - Now, when economics are run, it will pool C\*ERP at the ring fence
    level and run the child wells at 5% royalty until the pool is
    exhausted
  - Ring fence entities can now be children of CTEs, to facilitate total
    project evaluations but do the royalty calculation on the
    ERP-eligible wells only
- Now using reference prices, not par prices, to value royalty revenue
- Adjusted BOE ratio to match published 1.7811

## Bug Fixes

### Economic

- Fixed an issue when using a General interest, where
  Value
  Navigator would sometimes select an incorrect production
  category for non-primary products
- Fixed an issue in shared calculations (CTEs and ring fences) where
  current-year production could be excluded from cases that became
  uneconomic in the producing period

### Other

- Fixed an issue where the map would sometimes not detect an internet
  connection
- Fixed an issue where checking out a license to work offline and
  leaving the license manager open would revert back to an online
  license
- Fixed an issue where upgrades could fail if there is an empty parent
  plan
