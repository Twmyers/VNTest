

# 2017 v1.2 Release Notes

## Bug Fixes

- Fixed an issue with O+W forecasts in combination with 1+WOR where the
  forecast duration could change upon well copying or promotion. This
  would lead to unbalanced results in the Pending or Accepted copies
  after promoting from a balanced Working copy.
- Fixed an issue with the O+W calculation where it would incorrectly
  determine the point of a max-rate transition. This would manifest in
  different ways:
- Segment duration shown on the Declines tab not matching the graph
- Final rate (Qf) on O+W segments not always being honoured
- Forecasts terminating at O+W end date instead of oil end date
- Production gaps at segment transitions
