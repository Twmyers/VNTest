

# 2020 v1.1 Release Notes

## Bug Fixes

- Fixed a sorting issue on the Cross Plots tab, where normalized values
  in the well table would sometimes be displayed on the row for the
  wrong well.
- Fixed an error in the payout calculation that could happen on wells
  with gaps in cash flow streams. This would sometimes cause no results
  to be calculated for the well, and in rare circumstances could yield a
  deadlock where calculations never completed.
- Fixed an error that could occur with Report Designer reports, where
  the inclusion of custom reserves categories in a report (e.g., in a
  hierarchy table or Area Property report) would cause the report to
  fail to run. Such reports from VN 2020 will need to be rebuilt for VN
  2020 v1.1.
- Fixed a bug in BC royalty incentive calculations where floating-point
  precision issue could cause a calculation error as royalty balances
  were reduced to near-zero. This could affect all Deep Gas incentives
  and Discovery Oil.
