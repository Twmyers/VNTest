

# 2020 v1.2 Release Notes

- Fixed an issue where Canadian royalty outputs from custom fiscal
  regimes were not correctly included in Net Operating Income and
  Before-Tax Cash Flow.
- Added the ability to display plug-in economic indicators on
  the Economic \| Comparison tab.
- Added a MACRS15 tax pool (labeled "Pipelines and Facilities") to the
  built-in US tax pools. No new cost definitions were added, so a custom
  cost definition must be added in order to use this pool. This pool is
  subject to the same 2018-2026 bonus depreciation schedule as other US
  tangible pools.
- Fixed an issue where adding a new reserves category could yield a
  broken inheritance chain for child plan forecasts. Added an upgrade
  step to correct this issue if present in 2020 and 2020 v1.1 databases.
  Because of this required upgrade logic, the schema version number has
  been updated. This means v1.2 is not backwards compatible with those
  earlier versions, despite no schema changes being made.
- Fixed an issue where VN could crash or fail to open a database where
  the new database did not have the same plan/rescat structure as the
  previously open project.
- Fixed an issue where child plan economic calculations would not
  correctly inherit non-Common cost data (capital, operating, and
  abandonment/salvage) from parent plans.
- Fixed an issue where a custom regime Expense stream would not be
  deducted from US state taxable income.
- Fixed an issue where custom economic calculation plug-ins would not
  work with plug-in version fallback (e.g., where plug-ins
  built/installed for VN 2020 would not work for VN 2020 v1.2
  automatically). Only impacted custom economic calculations or
  indicators, not normal UI plug-ins.
- Fixed an issue where partial archives would fail to upgrade to
  VN 2020. Did not affect full archives.
