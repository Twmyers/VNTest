

# 2020 v1.3 Release Notes

- Fixed an issue in common termination entity (CTE) calculations that
  could prevent the calculation from finishing with a "max iteration
  count reached" error.
- Fixed a problem in the balancing dialog that would prevent the
  'Current' reserves category option being displayed.
- Fixed an issue where when locking a project could yield an error with
  certain security configurations.
- Fixed an issue where currency conversion was not correctly applied to
  floating salvage costs.
- Introduced a new project option to allow for aligning depreciation to
  the on-production date of projects instead of the spend date. Will
  only be applied to the well-level calculation and not folders or other
  aggregates.
- Updated the after-tax prorating and discounting logic to better
  account for mid-year start dates and mid-year reference dates when
  calculating mid-month depreciation. This will impact after-tax ROR
  calculations and any prorated after-tax reports. Whenever possible,
  the logic will now prorate from the start of the case instead of
  always spreading the annual tax value across the full year.”
