

# 2022 v2.1 Release Notes

## Enhancements

The following enhancements were added in this version:

- Added a key in the application config file to turn off cleanup of
  unused economic results. (**Warning**: Cleanup of unused economic
  results should only be turned off if economic cleanup is being run by
  a separate, customer-owned process like a stored procedure. This
  setting is ignored for VNDB files, which run SQL-Lite.)
- Added all user scenarios to the Clear Economic Output dialog.

## Bug Fixes

The following issues were fixed in this version:

- Fixed an issue where the performance of decline graph rendering
  degraded during a session, especially in projects with large amounts
  of daily data.
- Fixed an issue where large data sets caused the map to open much
  slower than previous versions.
