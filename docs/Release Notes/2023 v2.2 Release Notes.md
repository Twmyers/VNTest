

# 2023 v2.2 Release Notes

- Enabled forecast variance to use op-event-affected forecasts.
- Fixed an issue where product segments would occasionally not be
  generated when daily data fitting was enabled.
- Fixed an issue that caused upgrades of databases with archived plan
  colours to fail.
- Fixed an issue with forecasts when multiple volume-preserving
  operational events were used​ during periods containing segment
  transitions.
