

# 2024 v2.1 Release Notes

## Enhancements

- Changed the Schedule data area Data View and Spreadsheet Import for
  more intuitive imports and updates. Now, each activity date is a
  column instead of a row.

## Bug Fixes

- Fixed an issue where the Schedule data area Data View could not load
  more than 1,000 entities in Oracle.
- Fixed an issue where decline imports containing blank start dates were
  blocked from being imported to type wells.
- Fixed an issue where type well link imports could not be mapped.
