

# Automated Reserves Reconciliation Overview

Automated reserves reconciliation (ARR) is designed to simplify
reconciliations by eliminating the need to manually create a change
record each time you modify an entity. With ARR enabled,
Value
Navigator detects the changes you made and creates all the
required change records when you click Reconcile.

For example, with non-automated reserves reconciliation, you should
create a Change Record (and specify the Change Record Category) after
each type of change that you make in order to document the changes
separately. With ARR, you can make several types of changes and then
click Reconcile.
Value
Navigator will create separate Change Records for each change
type and automatically determine the Change Record Category to use.

## Upgraded vs. New Projects

Automated reserves reconciliation (ARR) is enabled by default in any
project created in
Value
Navigator 2018 or later (you can still create change records
manually). However, ARR is not enabled by default in any project
upgraded to
Value
Navigator 2018 or later. For upgraded projects, you must enable
ARR in the project options. See
[Enable Automated Reserves Reconciliation](Enable%20Automated%20Reserves%20Reconciliation.md) .
