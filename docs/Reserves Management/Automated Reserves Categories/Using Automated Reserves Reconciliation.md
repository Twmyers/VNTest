

# Using Automated Reserves Reconciliation

To use automated reserves reconciliation (ARR), complete the following
steps first:

- Import opening balances using the [Import Spreadsheet Data Overview](../../Importing%20and%20Exporting/Spreadsheet%20Import/Spreadsheet%20Import.md). This step is
  required if you are not working with a posted project. The opening
  balances are required so
  Value
  Navigator can compare the current value of entities. You can
  use ARR without opening balances, but you must assign each entity a
  Change Reason.
- [Enable Automated Reserves Reconciliation](Enable%20Automated%20Reserves%20Reconciliation.md)
- [Create or Edit Change Record Categories or Summary Types](../Review%20Change%20Records%20Overview/Create%20or%20Edit%20Change%20Record%20Categories%20or%20Summary%20Types.md)
- [Specify a Change Record Sequence](Specify%20a%20Change%20Record%20Sequence.md)
- [Specify a Change Reason on Wells](Specify%20a%20Change%20Reason%20on%20Wells.md)
- If you have completed the steps above, see
  [Auto Reconcile Wells](Auto%20Reconcile%20Wells.md).
