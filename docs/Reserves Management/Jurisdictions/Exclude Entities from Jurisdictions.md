



# Exclude Entities from Jurisdictions

When you create a jurisdiction, it includes all entities in the project
by default.



If a well is not “In Reserves”, it is not included in any jurisdiction
calculations or reports even if it has not been removed from a
jurisdiction. See Designate Entities as In Reserves or Out of Reserves.



To remove an entity from a jurisdiction

1.  Go to **Wells and General Economics \| Well Info and Custom
    Fields**.

2.  Scroll to the **In Jurisdiction** \ column.

3.  Remove the checkmark from the entity you want to exclude.

4.  Click **Save**.
