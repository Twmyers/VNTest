



# Review \| Change Records Overview

You can use the **Review \| Change Records** tab to balance one entity
(create a change record), view/edit change record data, or delete change
records. See
[Balance Entities](Balance%20Entities.md), [Create or Edit Change Record Categories or Summary Types](Create%20or%20Edit%20Change%20Record%20Categories%20or%20Summary%20Types.md), and
[Delete Change Records](Delete%20Change%20Records.md).

In the change record display window on the left of **Review \| Change
Records**, change records are organized by change record category (if
**Group Records by Category** is selected). The icons next to the change
records indicate the reserves plan in which the change record resides
(see the table, below). Note that the icon does not necessarily indicate
the plan in which the record was *created*. When you copy data from one
plan to another, the change records are also copied to the destination
plan (a copy does not remain in the original plan).

When you are working in the Working plan, change records for all plans
are visible in the display window on **Review \| Change Records**. When
you are working in Pending, only change records in Pending and Accepted
are visible. When you are working in Accepted, only change records in
Accepted are visible.

In the grid at the bottom of **Review \| Change Records**, a red dot
(![](../../Images/Review-Change-Records-Overview-4.jpg)) is displayed in the first column when an entity is
unbalanced.

Use the **Show Columns** list to specify which data is displayed in the
grid (Working Interest, Company Share, and Net).
