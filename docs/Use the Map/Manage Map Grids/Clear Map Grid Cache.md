



# Clear Map Grid Cache

To clear the map grid cache

1.  On the **Map** tab, click ![](../../Images/Clear-Map-Grid-Cache-1.png) and then click
![](../../Images/Clear-Map-Grid-Cache-2.png).
2.  Under Grid Options, click **Clear Cache**.
3.  Click **OK**.



The **Clear Cache** button is disabled when **Enable grid** is
selected.
