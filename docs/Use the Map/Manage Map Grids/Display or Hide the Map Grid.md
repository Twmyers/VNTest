



# Display or Hide the Map Grid

The Grid option under System Layers is only displayed if it is enabled
in the map options. See
[Enable or Disable the Map Grid](Enable%20or%20Disable%20the%20Map%20Grid.md).

To display or hide the map grid

1.  On the **Map** tab, click ![](../../Images/Display-or-Hide-the-Map-Grid-1.png).
2.  Under System Layers, select or deselect **Grid**.
