



# Enable or Disable Automatic Map Grid Updates

To enable or disable map grid updates

1.  On the Map tab, click ![](../../Images/Enable-or-Disable-Automatic-Map-Grid-Updates-1.png) and then click
![](../../Images/Enable-or-Disable-Automatic-Map-Grid-Updates-2.png).
2.  Select or deselect **Automatic updates**.
3.  Click **OK**.
