



# Enable or Disable the Map Grid

Enabling the map grid option causes the Grid checkbox to be displayed
under System Layers on the Map tab. Disabling the map grid option
removes the Grid option from System Layers.

To enable or disable map grids

1.  On the **Map** tab, click ![](../../Images/Enable-or-Disable-the-Map-Grid-1.png).
2.  Click ![](../../Images/Enable-or-Disable-the-Map-Grid-2.png) and select or deselect **Enable Grid**
