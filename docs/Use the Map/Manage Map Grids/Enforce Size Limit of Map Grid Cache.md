



# Enforce Size Limit of Map Grid Cache

To enforce a size limit on the map grid cache

1.  On the **Map** tab, click ![](../../Images/Enforce-Size-Limit-of-Map-Grid-Cache-1.png) and then click
![](../../Images/Enforce-Size-Limit-of-Map-Grid-Cache-2.png).
2.  Select a size from the **Maximum** list.
3.  Click **OK**.
