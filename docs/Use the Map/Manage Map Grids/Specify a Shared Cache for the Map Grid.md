



# Specify a Shared Cache for the Map Grid

To specify a shared cache for the map grid

1.  On the **Map** tab, click ![](../../Images/Specify-a-Shared-Cache-for-the-Map-Grid-1.png) and then click
![](../../Images/Specify-a-Shared-Cache-for-the-Map-Grid-2.png).
2.  Under **Grid options**, click ![](../../Images/Specify-a-Shared-Cache-for-the-Map-Grid-3.png) next to **Cache** to
    specify another folder.
3.  Select the **Shared cache** checkbox.
4.  Click **OK**.
