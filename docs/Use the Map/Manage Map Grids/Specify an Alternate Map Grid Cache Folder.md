



# Specify an Alternate Map Grid Cache Folder

You must have Administrator rights to specify an alternate map grid
cache folder.

To specify the map grid folder

1.  On the **Map** tab, click ![](../../Images/Specify-an-Alternate-Map-Grid-Cache-Folder-1.png) and then click
![](../../Images/Specify-an-Alternate-Map-Grid-Cache-Folder-2.png).
2.  Under **Grid options**, click ![](../../Images/Specify-an-Alternate-Map-Grid-Cache-Folder-3.png) next to **Cache** to
    specify another folder.
3.  Click **OK**.
