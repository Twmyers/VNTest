



# Specify the Map Grid Source

You must have Administrator rights to specify the map grid source.

To specify the map grid source

1.  On the **Map** tab, click ![](../../Images/Specify-the-Map-Grid-Source-1.png) and then click
![](../../Images/Specify-the-Map-Grid-Source-2.png).
2.  Under **Grid options**, paste a grid URL into the **URL** field.
3.  Click **OK**.
