



# Update Map Grids

To update Map Grids

1.  On the **Map** tab, click ![](../../Images/Update-Map-Grids-1.png) and then click
![](../../Images/Update-Map-Grids-2.png).
2.  Under **Grid Options**, do one of the following:
    - Select **Automatic Updates**
    - Click **Update**



1.  Click **OK**.



The **Update Now** button is only enabled if **Automatic Updates** is
not selected.
