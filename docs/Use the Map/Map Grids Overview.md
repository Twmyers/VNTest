



# Map Grids Overview

The following grids are used for Canada and the U.S.

## Canadian Map Grids

|                                 |      |          |
|---------------------------------|------|----------|
| Map Area                        | Grid | Detail   |
| Alberta, Saskatchewan, Manitoba | DLS  | LSD      |
| B.C.                            | NTS  | 1/4 Unit |
| Peace River Block               | DLS  | LSD      |
| Northern Territories            | FPS  | Section  |
| East Coast offshore             | FPS  | Section  |
