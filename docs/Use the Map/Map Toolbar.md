



# Map Toolbar

The map toolbar is displayed on the **Map** tab**.**



![](../Images/Map-Toolbar-1.jpg)



| Icon | Icon Name | Description |
|----|----|----|
| 

![](../Images/Map-Toolbar-2.png)

 | Manage Layers | Opens the Layers configuration panel. |
| 

![](../Images/Map-Toolbar-3.png)

 | Pan Mode\* | Click to grab the map and move to it to view the desired area. |
| 

![](../Images/Map-Toolbar-4.png)

 | Selection Mode\* | Click, hold and drag to select a portion of the map. |
| 

![](../Images/Map-Toolbar-5.png)

 | Zoom mode\* | Click, hold and drag to select an area of the map to zoom in to. |
| 

![](../Images/Map-Toolbar-6.png)

 | Zoom to project | Zoom and re-center map to include the entire current project. |
| 

![](../Images/Map-Toolbar-7.png)

 | Zoom to selection | Zooms to the entity selected either in the Entity Hierarchy, or on the map. |
| 

![](../Images/Map-Toolbar-8.png)

 | Zoom In | Click to zoom in on the map by increments of two. |
| 

![](../Images/Map-Toolbar-9.png)

 | Zoom Out | Click to zoom out from the map by increments of two. |
| 

![](../Images/Map-Toolbar-10.png)

 | Go to location | Click to open the Pan to Location dialog box. See [Pan to Location](Pan%20to%20Location.md). |
| 

![](../Images/Map-Toolbar-2.png)

0 | Show legend | Displays or hides the map legend when Data Visualization is enabled. . |
| 

![](../Images/Map-Toolbar-2.png)

1 | Print | Opens the Print preview |
| 

![](../Images/Map-Toolbar-2.png)

2 | Refresh | Refreshes the entire map and all layers. |
| 

![](../Images/Map-Toolbar-2.png)

3 | Pop out map | Opens the map in a new window. |
| 

![](../Images/Map-Toolbar-2.png)

4 | Go offline | Click to go offline. When you go offline, use this button to go back online. When you go offline, ValNav does not automatically connect when restarted or when a connection becomes available. |
| 

![](../Images/Map-Toolbar-2.png)

5 | Stop currently running map operations | Cancels map operations. |
| 

![](../Images/Map-Toolbar-2.png)

6 | About the map | Displays a dialog with basic map parameters and diagnostic information |



The **Select**, **Zoom**, and **Pan** functions are also available
through shortcut keys. See
[Map Shortcut Keys](Map%20Shortcut%20Keys.md).
