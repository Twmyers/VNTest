



# Print the Map

Once you have configured your map to display the desired entities and
bubbles at the desired zoom level, you can print the map. When you print
the map, all selected wells are printed, including those not visible on
the **Map** tab.

To print a map

1.  On the **Map** tab, click ![](../Images/Print-the-Map-1.png).
2.  In The **Print Preview** click ![](../Images/Print-the-Map-1.png).
3.  In the **Print** dialog box, click **OK** to print an image of the
    map, along with an annotation page of all the wells displayed on the
    map.



You can also click the **Export** button in the **Print Preview** window
to save the map in a different file format, such as a .pdf file.
