



# Filter to Selected Entities on the Map

To select and filter to entities on the map

1.  On the **Map** tab, click ![](../../Images/Filter-to-Selected-Entities-on-the-Map-1.png) to enter selection mode.
2.  Do one of the following on the map:
    - Right-click an entity
    - Hold the left mouse button and drag the square around several
      entities



1.  Right-click the selection and select **Filter to Selection** to
    filter the Entity Hierarchy to the selected entities.

To clear the filter, click ![](../../Images/Filter-to-Selected-Entities-on-the-Map-2.jpg) in the main toolbar.
