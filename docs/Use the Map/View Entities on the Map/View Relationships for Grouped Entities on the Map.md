

# View Relationships for Grouped Entities on the Map

The map displays entity relationships by drawing lines between parent
and child entities. The **Relationships** checkbox in the map options is
enabled by default. Use the procedure below to enable or disable the
Relationships checkbox.

To view the relationships for grouped entities

1.  Select an entity (either on the map or in the Entity Hierarchy).
2.  On the **Map** tab, click ![](../../Images/View-Relationships-for-Grouped-Entities-on-the-Map-1.png) and then click
![](../../Images/View-Relationships-for-Grouped-Entities-on-the-Map-2.png).
3.  Select or deselect the **Relationships** checkbox.
4.  Click **OK**.

The relationship between the entities (i.e. all entities that make up a
group) will be indicated by a line connecting all of the entities.
