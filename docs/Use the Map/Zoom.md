

# Zoom

To zoom on the map, do one of the following on the **Map** tab:

| To | Do this |
|----|----|
| Zoom to a selected entity, | Click ![](../Images/Zoom-1.png). |
| Zoom to the project entities, | Click ![](../Images/Zoom-2.png). The map displays the smallest area of the map containing the wells in your project (even if some wells are not visible because they are not included in the filter). |
| Zoom the map view | Click ![](../Images/Zoom-3.png) or use the scroll wheel on your mouse. |
